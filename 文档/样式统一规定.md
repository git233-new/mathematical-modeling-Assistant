# 样式统一规定（DOCX 版式参数唯一权威）

> **只管**：页面、字体字号、行距、题注、公式/图片防遮挡、表格形态、防重排、校验入口、LaTeX 映射。
> **不管**：章节结构与命名 → `文档/论文写作.md §1.1`；篇幅与数量 → `文档/论文写作.md` 项目交付下限表；图表职责与文件命名 → `文档/图片闸门配置与绘图规范.md`；参考文献著录与年份 → `文档/论文写作.md §2.10`；附录内容 → `文档/论文写作.md §2.11`。

## 一、页面与节

| 项 | 规定 |
|---|---|
| 纸张 | A4 竖版（21 × 29.7 cm） |
| 页边距 | 上下 2.54 cm、左右 3.18 cm；任何一边 ≥2.5 cm（硬闸门） |
| 页码 | 页脚居中，Times New Roman 10pt，单倍行距，从摘要起连续编号 |
| 分节 | 全文单节为主；附录如分节须保持同一边距 |

## 二、题目、摘要与关键词

| 元素 | 字体 | 字号 | 加粗 | 对齐 | 段前/段后 | 行距 |
|---|---|---|---|---|---|---|
| 论文题目 | 黑体 | 16pt（三号） | 是 | 居中 | 0 / 0 | 多倍 1.25 |
| 摘要标题「摘 要」 | 黑体 | 14pt（四号） | 否 | 居中 | 7.8pt / 7.8pt | 多倍 1.25 |
| 摘要正文 | 宋体 | 12pt（小四） | 否 | 两端对齐 | 0 / 0 | 多倍 1.25 |
| 关键词行 | 宋体（「关键词：」加粗） | 12pt | 见左 | 两端对齐 | 0 / 0 | 多倍 1.25 |

## 三、标题层级

| 层级 | 字体 | 字号 | 对齐 | 段前/段后 | 行距 | 大纲级别 |
|---|---|---|---|---|---|---|
| 一级 | 黑体 | 14pt（四号） | 居中 | 7.8pt / 7.8pt | 多倍 1.25 | 0 |
| 二级 | 黑体 | 12pt（小四） | 左对齐 | 7.8pt / 7.8pt | 多倍 1.25 | 1 |
| 三级 | 黑体 | 12pt（小四） | 左对齐 | 7.8pt / 7.8pt | 多倍 1.25 | 2 |

- 标题行距与全文一致用**多倍 1.25**而非固定值：多倍按行高自适应，不裁剪 16pt 大字号；固定值（EXACTLY）禁止（见 §四）。一级标题可 `page_break_before`。

## 四、正文

| 项 | 规定 |
|---|---|
| 中文字体 | 宋体（eastAsia=SimSun，样式 `Normal`） |
| 西文字体 | Times New Roman（ascii/hAnsi，每个 run 显式写入） |
| 字号 | 12pt（小四） |
| 对齐 | 两端对齐（JUSTIFY） |
| 首行缩进 | 24pt（= 2 字符 × 12pt） |
| 行距 | **多倍 1.25**（`BODY_LINE_SPACING=1.25`，`MULTIPLE`） |
| 段前/段后 | 0 / 0；段间不留空行（样式闸门拦多连空行） |
| 颜色 | 全黑 RGB(0,0,0)，按有效颜色口径逐 run 校验 |
| 题注 | 宋体 12pt 居中，用"图表排序"样式：图题图下（段后 7.8pt）、表题表上（段前 7.8pt） |

## 五、公式（防遮挡）

- 一律 OMML（`m:oMath`）原生公式，独立成段，编号右对齐（居中/右制表位），编号 Times New Roman 12pt。
- **行距：多倍 1.25**；禁止固定值行距——固定值按行高裁剪公式，上下标、分式必被切掉（`_clipped_object_issues` 拒存）。
- 与上下文间距：段前/段后各 `FORMULA_CONTEXT_GAP_PT = 27` 磅，`keep_together` 防跨页断开。

## 六、图片（防遮挡）

- 图片独立成段、居中，段行距**多倍 1.25**；禁止固定值行距（固定值只露一条，`_clipped_object_issues` 拒存）。
- 默认宽 12cm（按版面 10–14cm），不超页宽；源图 dpi ≥300、图中文字 ≥11pt 且全中文（SimHei 打头，参数真源 `tools/figure/templates/mm_style.py`）。
- 题注（`图N …`）紧随图下方，宋体 12pt 居中。
- 符号说明表整表内容居中、符号正体、不跨行，禁公式/equation 注入。

## 七、表格

- 正文：三线表（顶线 + 表头线 + 底线，无竖线）；两线表/网格表拒存。
- 正文大型数据表允许闭合方框表；附录清单表必须三线表，缺表线拒存（`_appendix_boxed_table_issues`）。
- **三线表各列平均分布等宽**：等分正文版心宽铺满（`three_line_table` → `_assign_three_line_widths`）。
- 表头黑体、单元格正文宋体；表题在表上方（`表N …`）。

## 八、防 Word 自动重排（打开即变形的根因与防护）

| 根因 | 防护 |
|---|---|
| 文档网格（docGrid）按行网格拉伸/压缩行距 | 移除所有节级 `w:docGrid`（`_disable_document_grid`） |
| "对齐到网格"（snapToGrid）随网格重排 | 样式与 docDefaults 一律 `w:snapToGrid=0` |
| 主题字体缺失导致替换、样式继承漂移 | 每 run 显式写直接格式化：中文字体 + Times New Roman + 字号 + 黑色（`set_run_font`） |
| 固定值行距裁剪对象 | 公式/图片段落强制多倍行距（§五/§六 + 硬闸门） |
| 标题样式被 Word 自动重定义（autoRedefine） | `_disable_heading_auto_redefine` 移除标题样式的 `w:autoRedefine`；样式由代码重建注入 |

## 九、机器校验入口

- 生成层：`paper_format.new_document()`（样式注入 + 防重排）→ `pf.preflight_check(outline)` → 逐元素写入 → `save_document()`。
- 硬闸门（任一不过拒存）：`validate_paper_structure()` = 篇幅/排版 + 全黑字体 + 禁用词 + 三线表/方框表 + 公式密度 + 固定值行距含公式/图片（`_clipped_object_issues`）+ 图片文件名规范（`_figure_filename_issues`）+ 参考文献年份。
- 行距常量 `paper_format.BODY_LINE_SPACING = 1.25`；其余阈值 `contest_profile.py`。

## 十、LaTeX 源码版交付物（完整论文.tex）

- `save_document()` 终态校验通过后、DOCX 发布前，由 `tools/docx/core/latex_export.export_latex_source` 从**同一内容快照**写出 `完整论文.tex`——先 tex 后 docx，两版不漂移；不编译、不产出 PDF、不要求本机 LaTeX 环境。`ctexart` 字体集**固定 `fontset=fandol`**（Overleaf/本地 TeX Live 开箱可用）；推荐 XeLaTeX。
- 结构映射（源码版只保证结构与内容一致，精细排版以 DOCX 交付版为准）：

| DOCX | LaTeX |
|---|---|
| 论文题目（黑体16pt居中） | `\documentclass[zihao=-4,a4paper]{ctexart}` + 文首题目段 |
| 一/二/三级标题 | `\section*`/`\subsection*`/`\subsubsection*`（保留"一、"编号文字） |
| 正文（宋体小四、缩进2字符、多倍 1.25） | `\linespread{1.25}` + `\parindent=2em`；geometry 与 `setup_page` 边距一致 |
| 公式（equation() 写入的原始 LaTeX） | `\begin{equation}…\end{equation}`，原样输出不转义（`record_equation_source`） |
| 图片 + 图题（`图N …`） | `\begin{figure}` + `\includegraphics{results/图片/<文件名>}` + `\caption*` |
| 表题 + 三线表 | `\caption*` + booktabs `tabular` |
| 附录A 支撑材料清单（三线表） | booktabs `tabular` |
| 参考文献（GB/T 7714） | `thebibliography` + `\bibitem` |
| 关键词行 | `\noindent\textbf{关键词：}…` |

- 交付保护：`完整论文.tex` 与 `完整论文.docx` 同级列入清理器 `PROTECTED_ITEMS`，重跑随 DOCX 一同覆盖。
