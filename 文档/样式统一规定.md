# 样式统一规定（DOCX 排版参数唯一权威）

> **用途**：论文 DOCX 的页面、字体、字号、行距、间距、题注、对象防遮挡与 LaTeX 映射等**排版参数**的唯一权威。本文件只回答"长什么样"。
> **不管**（一律引用，不重抄）：
> - 章节内容、写法、篇幅预算、结构顺序 → `文档/论文写作.md`
> - 图表文件命名与图表闸门 → `文档/图片闸门配置与绘图规范.md §2`
> - 出图样式与落盘命名执行 → `文档/代码规范.md`
> - 交付阈值（页数/字数/图表数/公式数/参考文献年份）→ `文档/论文写作.md` 项目交付下限表 + `contest_profile.py`
> **依赖**：无
> **被引**：`文档/论文写作.md`、`tools/docx/core/paper_format.py`、`tools/docx/core/structure_validation.py`

## 一、页面与节

| 项 | 规定 |
|---|---|
| 纸张 | A4 竖版（21 × 29.7 cm） |
| 页边距 | 上下 2.54 cm、左右 3.18 cm；任何一边 ≥2.5 cm（硬闸门） |
| 页码 | 页脚居中，Times New Roman 10pt，单倍行距，从摘要起连续编号 |
| 首页 | 无目录；摘要页版式（独占/分页/字数）写作要求与自检见 `文档/摘要写作范式.md §二` |
| 分节 | 全文单节为主；附录如分节须保持同一边距 |

## 二、题目、摘要与关键词

| 元素 | 字体 | 字号 | 加粗 | 对齐 | 段前/段后 | 行距 |
|---|---|---|---|---|---|---|
| 论文题目 | 黑体 | 16pt（三号） | 是 | 居中 | 0 / 0 | 多倍 1.25 |
| 摘要标题「摘 要」 | 黑体 | 14pt（四号） | 否 | 居中 | 7.8pt / 7.8pt | 多倍 1.25 |
| 摘要正文 | 宋体 | 12pt（小四） | 否 | 两端对齐 | 0 / 0 | 多倍 1.25 |
| 关键词行 | 宋体（「关键词：」加粗） | 12pt | 见左 | 两端对齐 | 0 / 0 | 多倍 1.25 |

- 关键词数量与措辞、摘要结构见 `文档/摘要写作范式.md`；图表编号不进摘要（摘要措辞规范见 `文档/去AI味指南.md`）。

## 三、标题层级

| 层级 | 字体 | 字号 | 加粗 | 对齐 | 段前/段后 | 行距 | 其他 |
|---|---|---|---|---|---|---|---|
| 一级（一、二、…） | 黑体 | 14pt（四号） | 否 | 居中 | 7.8pt / 7.8pt | 多倍 1.25 | 可 `page_break_before`；大纲级别 0 |
| 二级（2.1 …） | 黑体 | 12pt（小四） | 否 | 左对齐 | 7.8pt / 7.8pt | 多倍 1.25 | 大纲级别 1 |
| 三级（2.1.1 …） | 黑体 | 12pt（小四） | 否 | 左对齐 | 7.8pt / 7.8pt | 多倍 1.25 | 大纲级别 2 |

- **编号体系全文统一**：一级用中文序号（一、二、…）（摘要不编号）；二级 `1.x`；三级 `1.m.n`；不混用，大纲级别对应上表 0/1/2。标题如何命名、必备一级标题有哪些，见 `文档/论文写作.md §1.1`。
- 标题行距与全文一致用**多倍 1.25**而非固定值：多倍按行高自适应，不裁剪 16pt 大字号；固定值（EXACTLY）仍禁止（见 §五）。

## 四、正文

| 项 | 规定 |
|---|---|
| 中文字体 | 宋体（ eastAsia=SimSun，样式 `Normal`） |
| 西文字体 | Times New Roman（ascii/hAnsi，每个 run 显式写入） |
| 字号 | 12pt（小四） |
| 对齐 | 两端对齐（JUSTIFY） |
| 首行缩进 | 24pt（= 2 字符 × 12pt） |
| 行距 | **多倍 1.25**（全文统一，`BODY_LINE_SPACING=1.25`，`MULTIPLE`） |
| 段前/段后 | 0 / 0；段间不留空行（样式闸门拦多连空行） |
| 颜色 | 全黑 RGB(0,0,0)，按有效颜色口径逐 run 校验 |
| 题注 | 宋体 12pt 居中，用"图表排序"样式：图题图下（段后 7.8pt）、表题表上（段前 7.8pt） |

## 五、公式（防遮挡）

- 一律 OMML（`m:oMath`）原生公式，独立成段，编号右对齐（居中/右制表位实现），编号 Times New Roman 12pt。
- **行距：多倍 1.25**（与全文一致）。禁止固定值行距——固定值按行高裁剪公式，上下标、分式必被切掉（`_clipped_object_issues` 硬闸门拒存）。
- 与上下文间距：段前/段后各 `FORMULA_CONTEXT_GAP_PT = 27` 磅（独立留白常量，与行距解耦），`keep_together` 防跨页断开。
- 公式数量与写法（定义/依据/推导/结论）见 `文档/论文写作.md`（项目交付下限表 / §2.6）。

## 六、图片（防遮挡）

- 图片独立成段、居中，段行距**多倍 1.25**；禁止固定值行距——固定值按行高裁剪图片，只露一条（`_clipped_object_issues` 硬闸门拒存）。
- 默认宽 12cm（按版面 10–14cm），不超页宽；源图 dpi ≥300、图中文字 ≥11pt 且全中文（SimHei 打头）、坐标轴/图例/单位齐全（出图参数真源 `tools/figure/templates/mm_style.py`；中文标签红线见 `文档/代码规范.md` 出图铁律）。
- 题注（`图N …`）紧随图下方，宋体 12pt 居中；图必须在正文引用；编号连续。
- 图表分工：结构图解释对象、流程图解释步骤、曲线解释动态过程、比较表解释方案优劣、敏感性图解释稳健范围。
- **文件命名（图/表数据文件）**：唯一权威见 `文档/图片闸门配置与绘图规范.md §2`（机器判法 `_figure_filename_issues`）。
- 符号说明表：整表内容居中、符号正体、不跨行，与数学公式无关，禁公式/equation 注入。

## 七、表格

- 正文：三线表（顶线 + 表头线 + 底线，无竖线）；两线表/网格表拒存。代码不入论文。
- 附录：附录A 支撑材料清单用三线表，缺表线拒存（`_appendix_boxed_table_issues`）。
- **三线表各列平均分布等宽**：等分正文版心宽铺满（`three_line_table` → `_assign_three_line_widths`），不再给符号列留 40% 特权宽。
- 表头黑体、单元格正文宋体；表题在表上方（`表N …`），正文须引用。
- 正文大型数据表允许闭合方框表，形态细则同属本条；表格内容与取舍见 `文档/论文写作.md`。

## 八、参考文献

- 著录 GB/T 7714：`[J] [C] [M] [D] [R] [S] [P] [DS/OL] [EB/OL]`；正文引用 `[1]`/`[1-3]`，与文献表双向核对。
- 年份门禁、数量闸门与真实性核验见 `文档/论文写作.md §2.10` 与项目交付下限表（常量 `contest_profile.REFERENCE_MIN_YEAR`）。

## 九、附录

- 附录A 支撑材料清单用三线表，**两列：文件名 | 功能与作用**——文件名列只写纯文件名（相对目录信息在 `run_manifest.json` 的 source 字段），功能由 `pf._support_role` 按文件命名约定自动推断；内容与生成方式见 `文档/论文写作.md §2.11`。代码本体不入论文，全部保留在 `code/` 目录。

## 十、防 Word 自动重排（打开即变形的根因与防护）

| 根因 | 防护 |
|---|---|
| 文档网格（docGrid）按行网格拉伸/压缩行距 | 移除所有节级 `w:docGrid`（`_disable_document_grid`） |
| "对齐到网格"（snapToGrid）随网格重排 | 样式与 docDefaults 一律 `w:snapToGrid=0` |
| 主题字体缺失导致替换、样式继承漂移 | 每 run 显式写直接格式化：中文字体 + Times New Roman + 字号 + 黑色（`set_run_font`） |
| 固定值行距裁剪对象 | 公式/图片段落强制多倍行距（§五/§六 + 硬闸门） |
| 标题样式被 Word 自动重定义（autoRedefine） | `_disable_heading_auto_redefine` 移除标题样式的 `w:autoRedefine`；样式由代码重建注入，不依赖模板继承 |

## 十一、机器校验入口

- 生成层：`paper_format.new_document()`（样式注入 + 防重排）→ `pf.preflight_check(outline)` → 逐元素写入 → `save_document()`。
- 硬闸门（任一不过拒存）：`validate_paper_structure()` = 篇幅/排版 + 全黑字体 + 禁用词 + 三线表/方框表 + 公式密度 + 固定值行距含公式/图片拒存（`_clipped_object_issues`）+ 图片文件名规范（`_figure_filename_issues`）+ 参考文献年份。
- 行距常量：`paper_format.BODY_LINE_SPACING = 1.25`（多倍）。

## 十二、LaTeX 源码版交付物（完整论文.tex）

- `save_document()` 在终态校验通过后、DOCX 发布前，由 `tools/docx/core/latex_export.export_latex_source` 从**同一内容快照**写出 `完整论文.tex`——先 tex 后 docx，两版内容不可能漂移；不编译、不产出 PDF、不要求本机有 LaTeX 环境。`ctexart` 字体集**固定 `fontset=fandol`**（随 TeX Live 分发，Overleaf/本地 TeX Live 开箱可用，pdfLaTeX/XeLaTeX 皆可；勿用 windows 字体集——Overleaf 无 SimSun/SimHei）；推荐 XeLaTeX 编译。
- 结构映射（源码版只保证结构与内容一致，精细排版以 DOCX 交付版为准）：

| DOCX | LaTeX |
|---|---|
| 论文题目（黑体16pt居中） | `\documentclass[zihao=-4,a4paper]{ctexart}` + 文首题目段 |
| 一/二/三级标题 | `\section*`/`\subsection*`/`\subsubsection*`（保留"一、"编号文字） |
| 正文（宋体小四、缩进2字符、多倍 1.25） | `\linespread{1.25}` + `\parindent=2em` 近似；geometry 与 `setup_page` 边距一致 |
| 公式（equation() 写入的原始 LaTeX） | `\begin{equation}…\end{equation}`，**原样输出不转义**（侧通道 `record_equation_source`） |
| 图片 + 图题（`图N …`） | `\begin{figure}` + `\includegraphics{results/图片/<文件名>}` + `\caption*` |
| 表题 + 三线表 | `\caption*` + booktabs `tabular` |
| 附录A 支撑材料清单（三线表） | booktabs `tabular` |
| 参考文献（GB/T 7714） | `thebibliography` + `\bibitem` |
| 关键词行 | `\noindent\textbf{关键词：}…` |

- 交付保护：`完整论文.tex` 与 `完整论文.docx` 同级列入清理器 `PROTECTED_ITEMS`，重跑随 DOCX 一同覆盖。
