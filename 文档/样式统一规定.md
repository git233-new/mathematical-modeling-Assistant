# 样式统一规定（唯一权威）

> 论文 DOCX 的全部版式数值以本文为唯一权威；代码权威为 `tools/docx/core/paper_format.py`（`_ensure_paper_styles` / `BODY_LINE_SPACING_PT` / `FORMULA_CONTEXT_GAP_PT`）与 `tools/docx/core/contest_profile.py`。`文档/论文写作.md` §三、`SKILL.md` 引用本文，不另设数值。母版：`文档/模板/2026数学建模国赛标准论文Word模板.docx`（提供页面基底与章节槽位；字体字号行距由 `_ensure_paper_styles` 统一注入）。

## 一、页面与节

| 项 | 规定 |
|---|---|
| 纸张 | A4 竖版（21 × 29.7 cm） |
| 页边距 | 上下 2.54 cm、左右 3.18 cm；任何一边 ≥2.5 cm（硬闸门） |
| 页码 | 页脚居中，Times New Roman 10pt，单倍行距，从摘要起连续编号 |
| 首页 | 摘要独立成页（含关键词），关键词后分页；无目录 |
| 分节 | 全文单节为主；附录如分节须保持同一边距 |

## 二、题目、摘要与关键词

| 元素 | 字体 | 字号 | 加粗 | 对齐 | 段前/段后 | 行距 |
|---|---|---|---|---|---|---|
| 论文题目 | 黑体 | 16pt（三号） | 是 | 居中 | 0 / 0 | 多倍 1.25 |
| 摘要标题「摘 要」 | 黑体 | 16pt（三号） | 否 | 居中 | 7.8pt / 7.8pt | 多倍 1.25 |
| 摘要正文 | 宋体 | 12pt（小四） | 否 | 两端对齐 | 0 / 0 | **固定 18 磅** |
| 关键词行 | 宋体（「关键词：」加粗） | 12pt | 见左 | 两端对齐 | 0 / 0 | **固定 18 磅** |

- 关键词 4–6 个，覆盖核心方法；摘要不用"本文/我们"，图表编号不进摘要。
- 摘要数字密度：数字字符占比 >18% 拒存、>10% 预警。

## 三、标题层级

| 层级 | 字体 | 字号 | 加粗 | 对齐 | 段前/段后 | 行距 | 其他 |
|---|---|---|---|---|---|---|---|
| 一级（一、二、…） | 黑体 | 14pt（四号） | 否 | 居中 | 7.8pt / 7.8pt | 单倍 | 可 `page_break_before`；大纲级别 0 |
| 二级（2.1 …） | 黑体 | 12pt | 是 | 左对齐 | 7.8pt / 7.8pt | 单倍 | 大纲级别 1 |
| 三级（2.1.1 …） | 黑体 | 12pt | 是 | 左对齐 | 7.8pt / 7.8pt | 单倍 | 大纲级别 2 |

- 必备一级标题（缺一拒存）：问题重述、问题分析、模型假设、符号说明、模型建立与求解、参考文献、附录；标题含"建立/建模"的小节必须 ≥1 个 oMath 公式。
- 标题行距用单倍而非固定值：固定值会裁剪 16pt 大字号（见 §五）。

## 四、正文

| 项 | 规定 |
|---|---|
| 中文字体 | 宋体（ eastAsia=SimSun，样式 `Normal`） |
| 西文字体 | Times New Roman（ascii/hAnsi，每个 run 显式写入） |
| 字号 | 12pt（小四） |
| 对齐 | 两端对齐（JUSTIFY） |
| 首行缩进 | 24pt（= 2 字符 × 12pt） |
| 行距 | **固定值 18 磅**（`BODY_LINE_SPACING_PT=18`，`EXACTLY`） |
| 段前/段后 | 0 / 0；段间不留空行（样式闸门拦多连空行） |
| 颜色 | 全黑 RGB(0,0,0)，按有效颜色口径逐 run 校验 |
| 题注 | 宋体 12pt 居中：图题段后 7.8pt、表题段前 7.8pt |

## 五、公式（防遮挡）

- 一律 OMML（`m:oMath`）原生公式，独立成段，编号右对齐（居中/右制表位实现），编号 Times New Roman 12pt。
- **行距：多倍 1.5**。禁止固定值行距——固定值按行高裁剪公式，上下标、分式必被切掉（`_clipped_object_issues` 硬闸门拒存）。
- 与上下文间距：段前/段后各 `FORMULA_CONTEXT_GAP_PT = 27` 磅（= 18 × 1.5），`keep_together` 防跨页断开。
- 公式数量：正文 15–25 个（`CUMCM_MIN/MAX_EQUATIONS`）。

## 六、图片（防遮挡 + 命名）

**插入与排版**

- 图片独立成段、居中，段行距**多倍 1.25**；禁止固定值行距——固定值按行高裁剪图片，只露一条（`_clipped_object_issues` 硬闸门拒存）。
- 默认宽 12cm（按版面 10–14cm），不超页宽；源图 dpi ≥300、图中文字 ≥11pt 且全中文（SimHei 打头）、坐标轴/图例/单位齐全。
- 题注（`图N …`）紧随图下方，宋体 12pt 居中；图必须在正文引用；编号连续。
- 图表分工：结构图解释对象、流程图解释步骤、曲线解释动态过程、比较表解释方案优劣、敏感性图解释稳健范围。

**文件命名（硬闸门 `_figure_filename_issues`）**

- 格式：`<全局序号>_<描述>.png`，序号为全库递增整数且**不得重复**。
- 描述两种形态：
  1. 全中文短语：`1_流程图.png`、`7_灵敏度分析.png`；
  2. 带问号归属：`2_Q1_数据清洗对比.png`、`3_Q1_均方根误差(RMSE).png`。
- 禁止：以「图N」开头（图号只写在题注，防编号脱节）；含纯英文/拼音缩写段（RMSE、AUC、R²、单位等通用缩写可保留）。
- 全部位于 `results/图片/`；重跑覆盖。数据文件同理用 `Q<序号>_<中文描述>.csv` 一类中文命名存 `results/数据/`（此处描述的是数据文件名，非代码入口 `Q<序号>.py`）。

## 七、表格

- 正文：三线表（顶线 + 表头线 + 底线，无竖线）；两线表/网格表拒存。
- 附录：闭合方框表（四边外框、无内部竖线），禁用三线表（`_appendix_boxed_table_issues` 强制）。
- 表头黑体、单元格正文宋体；表题在表上方（`表N …`），正文须引用。

## 八、参考文献

- 著录 GB/T 7714：`[J] [C] [M] [D] [R] [S] [P] [DS/OL] [EB/OL]`；正文引用 `[1]`/`[1-3]`，与文献表双向核对。
- **年份门禁：只收录 2016 年及之后的文献**（`contest_profile.REFERENCE_MIN_YEAR=2016`；条目带年份且早于下限即拒存，无年份条目不拦）。
- 真实条目经 `tools/paper_search/` 核验（`citation_ready=true` 才可入表）；占位/空壳条目拒存。

## 九、附录

- 附录A 支撑材料清单（`run_manifest.json` 的 `source_scripts` + 数据文件自动生成）；附录B/C/D… 各问核心代码（按 Q 聚类，`pf.append_code_files` 渲染，代码表前补"表N"题注）。
- 附录表格用方框表；正文文件名禁入正文（只允许泛指），具体文件名仅在附录/清单出现。

## 十、防 Word 自动重排（打开即变形的根因与防护）

| 根因 | 防护（`_disable_document_grid` + `set_run_font`） |
|---|---|
| 文档网格（docGrid）按行网格拉伸/压缩行距 | 移除所有节级 `w:docGrid` |
| "对齐到网格"（snapToGrid）随网格重排 | 样式与 docDefaults 一律 `w:snapToGrid=0` |
| 主题字体缺失导致替换、样式继承漂移 | 每 run 显式写直接格式化：中文字体 + Times New Roman + 字号 + 黑色 |
| 固定值行距裁剪对象 | 公式/图片段落强制多倍行距（§五/§六 + 硬闸门） |
| 样式被 Word 自动重定义 | 样式由代码重建注入，不依赖模板样式继承；交付时逐段核验样式映射 |

## 十一、机器校验入口

- 生成层：`paper_format.new_document()`（样式注入 + 防重排）→ `pf.preflight_check(outline)` → 逐元素写入 → `save_document()`。
- 硬闸门（任一不过拒存）：`validate_paper_structure()` = 篇幅/排版 + 全黑字体 + 禁用词 + 三线表/方框表 + 公式密度 + 摘要数字密度 + **固定值行距含公式/图片拒存（`_clipped_object_issues`）** + **图片文件名规范（`_figure_filename_issues`）** + **参考文献年份（≥2016）**。
- 数值阈值单一来源：`contest_profile.py`（`CUMCM_*`、`REFERENCE_MIN_YEAR`）；行距常量：`paper_format.BODY_LINE_SPACING_PT`。

## 十二、LaTeX 源码版交付物（完整论文.tex）

- `save_document()` 在终态校验通过后、DOCX 发布前，由 `tools/docx/core/latex_export.export_latex_source` 从**同一内容快照**写出 `完整论文.tex`——先 tex 后 docx，两版内容不可能漂移；不编译、不产出 PDF、不要求本机有 LaTeX 环境。
- 结构映射（源码版只保证结构与内容一致，精细排版以 DOCX 交付版为准）：

| DOCX | LaTeX |
|---|---|
| 论文题目（黑体16pt居中） | `\documentclass[zihao=-4,a4paper]{ctexart}` + 文首题目段 |
| 一/二/三级标题 | `\section*`/`\subsection*`/`\subsubsection*`（保留"一、"编号文字） |
| 正文（宋体小四、缩进2字符、固定18磅） | `\linespread{1.5}` + `\parindent=2em` 近似；geometry 与母版边距一致 |
| 公式（equation() 写入的原始 LaTeX） | `\begin{equation}…\end{equation}`，**原样输出不转义**（侧通道 `record_equation_source`） |
| 图片 + 图题（`图N …`） | `\begin{figure}` + `\includegraphics{results/图片/<文件名>}` + `\caption*` |
| 表题 + 三线表 | `\caption*` + booktabs `tabular` |
| 附录代码方框表 | `verbatim` 块 |
| 参考文献（GB/T 7714，≥2016） | `thebibliography` + `\bibitem` |
| 关键词行 | `\noindent\textbf{关键词：}…` |

- 交付保护：`完整论文.tex` 与 `完整论文.docx` 同级列入清理器 `PROTECTED_ITEMS`，重跑随 DOCX 一同覆盖。
