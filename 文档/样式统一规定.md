# 样式统一规定

> **用途**：论文 DOCX 全部版式数值与写作指导的唯一权威。
> **依赖**：无
> **被引**：`文档/论文写作.md`、`文档/七轮自审框架.md`、多处

## 一、页面与节

| 项 | 规定 |
|---|---|
| 纸张 | A4 竖版（21 × 29.7 cm） |
| 页边距 | 上下 2.54 cm、左右 3.18 cm；任何一边 ≥2.5 cm（硬闸门） |
| 页码 | 页脚居中，Times New Roman 10pt，单倍行距，从摘要起连续编号 |
| 首页 | 无目录；摘要页版式（独占/分页/字数）写作要求与自检见 `文档/摘要写作范式.md` §二 |
| 分节 | 全文单节为主；附录如分节须保持同一边距 |

## 二、题目、摘要与关键词

| 元素 | 字体 | 字号 | 加粗 | 对齐 | 段前/段后 | 行距 |
|---|---|---|---|---|---|---|
| 论文题目 | 黑体 | 16pt（三号） | 是 | 居中 | 0 / 0 | 多倍 1.25 |
| 摘要标题「摘 要」 | 黑体 | 14pt（四号） | 否 | 居中 | 7.8pt / 7.8pt | 多倍 1.25 |
| 摘要正文 | 宋体 | 12pt（小四） | 否 | 两端对齐 | 0 / 0 | **固定 18 磅** |
| 关键词行 | 宋体（「关键词：」加粗） | 12pt | 见左 | 两端对齐 | 0 / 0 | **固定 18 磅** |

- 关键词 4–6 个，覆盖核心方法；图表编号不进摘要（摘要措辞规范见 `文档/去AI味指南.md`）。

## 三、标题层级

| 层级 | 字体 | 字号 | 加粗 | 对齐 | 段前/段后 | 行距 | 其他 |
|---|---|---|---|---|---|---|---|
| 一级（一、二、…） | 黑体 | 14pt（四号） | 否 | 居中 | 7.8pt / 7.8pt | 单倍 | 可 `page_break_before`；大纲级别 0 |
| 二级（2.1 …） | 黑体 | 12pt（小四） | 否 | 左对齐 | 7.8pt / 7.8pt | 单倍 | 大纲级别 1 |
| 三级（2.1.1 …） | 黑体 | 12pt（小四） | 否 | 左对齐 | 7.8pt / 7.8pt | 单倍 | 大纲级别 2 |

**标题命名规则（全文唯一权威；结构模板与预算见 `文档/论文写作.md §1.1/§1.2`）**：
- **编号体系全文统一**：一级标题用中文序号（一、二、…）（摘要不需要序号）；二级 `1.x`；三级 `1.m.n`，不混用，大纲级别对应上表 0/1/2。
- **命名具体化**：二级/三级标题必须写具体方法或对象，不写泛称。反例："问题一求解""模型建立""结果分析"。正例："等距螺线参数与龙头初始状态""碰撞判定（SAT+两层保守预筛）""终止时刻搜索：粗扫定位与二分精修""沿问题四复合路径的两阶段速度放大扫描"。看目录即知技术路线。
- **骨架级标题不机械套**：一级可用"模型建立与求解"等骨架标题，其下小节按内容随名（`5.x` 按问题/模型主题/算法链分节），禁止把 `5.x.1/5.x.2/5.x.3` 写死为"模型建立/模型求解/结果分析"。

- **必备一级标题（缺一拒存）**：摘要、问题重述、问题分析、模型假设、符号说明、模型建立与求解、模型检验与分析、模型评价与改进、AI工具使用声明、参考文献、附录；标题含"建立/建模"的小节必须 ≥1 个 oMath 公式。
- 标题行距用单倍而非固定值：固定值会裁剪 16pt 大字号（见 §五）。

## 四、正文

| 项 | 规定 |
|---|---|
| 中文字体 | 宋体（ eastAsia=SimSun，样式 `Normal`） |
| 西文字体 | Times New Roman（ascii/hAnsi，每个 run 显式写入） |
| 字号 | 12pt（小四） |
| 对齐 | 两端对齐（JUSTIFY） |
| 首行缩进 | 24pt（= 2 字符 × 12pt） |
| 行距 | **固定值 18 磅**（`BODY_LINE_SPACING_PT=18`，`EXACTLY`） |
| 段前/段后 | 0 / 0；段间不留空行（样式闸门拦多连空行） |
| 颜色 | 全黑 RGB(0,0,0)，按有效颜色口径逐 run 校验 |
| 题注 | 宋体 12pt 居中：图题段后 7.8pt、表题段前 7.8pt |

## 五、公式（防遮挡）

- 一律 OMML（`m:oMath`）原生公式，独立成段，编号右对齐（居中/右制表位实现），编号 Times New Roman 12pt。
- **行距：多倍 1.5**。禁止固定值行距——固定值按行高裁剪公式，上下标、分式必被切掉（`_clipped_object_issues` 硬闸门拒存）。
- 与上下文间距：段前/段后各 `FORMULA_CONTEXT_GAP_PT = 27` 磅（= 18 × 1.5），`keep_together` 防跨页断开。
- 公式数量：正文 15–25 个（`CUMCM_MIN/MAX_EQUATIONS`）。

## 六、图片（防遮挡 + 命名）

**插入与排版**

- 图片独立成段、居中，段行距**多倍 1.25**；禁止固定值行距——固定值按行高裁剪图片，只露一条（`_clipped_object_issues` 硬闸门拒存）。
- 默认宽 12cm（按版面 10–14cm），不超页宽；源图 dpi ≥300、图中文字 ≥11pt 且全中文（SimHei 打头）、坐标轴/图例/单位齐全。
- 题注（`图N …`）紧随图下方，宋体 12pt 居中；图必须在正文引用；编号连续。
- 图表分工：结构图解释对象、流程图解释步骤、曲线解释动态过程、比较表解释方案优劣、敏感性图解释稳健范围。

**文件命名（图/表数据文件统一细则；唯一权威；机器登记与判法见 `文档/图片闸门配置与绘图规范.md` §2，代码为真源 `_figure_filename_issues`）**

- **图片**（`results/图片/`，硬闸门 `_figure_filename_issues` 强制）：
  - 格式：`<全局序号>_Q<问题号>_<描述>.png`，序号为全库递增整数且**不得重复**（重跑覆盖当前结果）。
  - 描述形态：
    1. `<序号>_Q<问题号>_<中文描述>.png`，如 `1_流程图.png`、`2_Q1_数据清洗对比.png`、`3_Q1_均方根误差(RMSE).png`；
  - 全局序号只图片需要（图进正文题注、防编号脱节）；表/数据文件不占该序号池。
- **表/数据文件**（`results/数据/`；溯源靠 `run_manifest.json` 登记路径+sha256，不带全局序号）：
  - 格式：`[Q<问号>_]<中文描述>.<ext>`——归属某问的结果表**必带** `Q<问号>_` 前缀，如 `Q1_模型验证.xlsx`、`Q1_匹配指数.csv`；全库共用/汇总类数据可不带问号前缀。
  - 格式约束：数据佐证优先 xlsx；csv 必须 `utf-8-sig`（带 BOM，否则 Excel 直接打开乱码）；json 仅限工具链登记（`run_manifest.json`、`spss_outputs.json`、`文献检索.json`）或赛题强制要求。
- **共同禁则**：以「图N」开头（图号只写题注，防编号脱节）；描述含纯英文/拼音缩写段（通用缩写白名单真源为 `structure_validation._ALLOWED_FILENAME_TOKENS`：RMSE/MAE/AUC/F1/ROC/SHAP/PCA/ph/max/min 等可保留；OR/CI/p/F 属表头语言白名单 `_ALLOWED_HEADER_TOKENS`，不适用于文件名）——`fig_q1.png`、`data_q1.csv` 均不合格。

## 七、表格

- 正文：三线表（顶线 + 表头线 + 底线，无竖线）；两线表/网格表拒存。
- 附录：只保留附录A 支撑材料清单，用三线表，缺表线拒存（`_appendix_boxed_table_issues`）。代码不入论文。
- 表头黑体、单元格正文宋体；表题在表上方（`表N …`），正文须引用。

## 八、参考文献

- 著录 GB/T 7714：`[J] [C] [M] [D] [R] [S] [P] [DS/OL] [EB/OL]`；正文引用 `[1]`/`[1-3]`，与文献表双向核对。
- **年份门禁：只收录 2016 年及之后的文献**（`contest_profile.REFERENCE_MIN_YEAR=2016`；条目带年份且早于下限即拒存，无年份条目不拦）。
- 真实条目经 `tools/paper_search/` 核验（`citation_ready=true` 才可入表）；占位/空壳条目拒存。

## 九、附录

- 附录A 支撑材料清单（`run_manifest.json` 的 `source_scripts` + 数据文件自动生成，`pf.append_code_files` 渲染三线表）；代码本体不入论文，全部保留在 `code/` 目录；正文文件名禁入正文（只允许泛指），具体文件名仅在附录清单出现。

## 十、防 Word 自动重排（打开即变形的根因与防护）

| 根因 | 防护 |
|---|---|
| 文档网格（docGrid）按行网格拉伸/压缩行距 | 移除所有节级 `w:docGrid`（`_disable_document_grid`） |
| "对齐到网格"（snapToGrid）随网格重排 | 样式与 docDefaults 一律 `w:snapToGrid=0` |
| 主题字体缺失导致替换、样式继承漂移 | 每 run 显式写直接格式化：中文字体 + Times New Roman + 字号 + 黑色（`set_run_font`） |
| 固定值行距裁剪对象 | 公式/图片段落强制多倍行距（§五/§六 + 硬闸门） |
| 标题样式被 Word 自动重定义（autoRedefine） | `_disable_heading_auto_redefine` 移除标题样式的 `w:autoRedefine`；样式由代码重建注入，不依赖模板继承 |

## 十一、图表写作指导

### 图文分布与引出（W9 预警）

- 每个 图N/表N 之前必须先有一行文字**引出**（说明该图/表展示什么、为何此处出现，一行即可）
- 之后紧跟**解释**（结果解读、与论点的关系）
- 先引出、再图表、后解释，禁止图表紧跟标题或连续堆图无过渡
- 全文逻辑连贯：图表的引出与解释必须与上下文形成因果链，不许孤立插入
- 图表按论证需要安排；结果图放首次解释处，后文只引图号；禁凑数硬塞、禁同图换题注重复使用

### 出图字体与中文标签

- 代码生成图片（流程图、曲线、热图、收敛图等）的中文标签、标题、图例、坐标名字体字号颜色遵循 `_ensure_paper_styles` 样式
- 中文标签黑体、字号 ≥11pt、dpi ≥300
- 图内文字不遮挡、不与图形重叠
- **图（坐标轴、图例、标题、注释、单位）内所有文字必须中文**——严禁 `False Positive Rate`、`Standard Deviation`、`Observed` 这类英文标签；通用缩写 `RMSE`/`AUC`/`R²`/单位可保留，轴名须中文（如 `均方根误差 (RMSE)`、`温度 (°C)`）

### 符号说明表特例

整表内容居中、符号正体、不跨行，与数学公式无关，禁公式/equation 注入。

## 十二、公式写作指导

### 公式写法（每式独占一段，显式编号）

1. **定义**：对象、变量、参数、单位，说明对应题目何量
2. **依据**：物理定律/统计定义/目标/约束的原始关系
3. **推导**：代入/联立/消元/离散化/积分/归一化 → 每步一式
4. **结论**：最终式用途、可求解变量、适用条件

```text
定义：设入射方向 u=(u_x,u_y)，法向量 n=(n_x,n_y)，||n||_2=1。
依据：反射方向等入射方向关于法向量的镜像。
LaTeX：r = u - 2(u·n)n
推导：分解 u，法向分量为 (u·n)n，反射后变号。
结论：r 给出反射方向，后续与目标平面联立即可求交点。
```

> 严禁：把"定义/推导/结论"塞一行、关键公式放附录或图片、手写编号文字。

### 公式分布

除总量下限外，**标题含"建立/建模"的小节必须 ≥1 个 oMath 公式**——建模无数理表达式不成立；空缺由 `_model_section_formula_issues` 判致命。

## 十三、其他通用写作规则

- **正文文件名禁用**：正文（不含附录、参考文献）不得出现任何文件名；引用代码/数据只用"脚本""数据文件""结果表"泛指，具体文件名只进附录或支撑材料清单。
- **题注**：用"图表排序"样式；图题图下、表题表上。
- **正文边界**：参考文献之前为正文；参考文献与附录不算正文，不入篇幅、图表计数与结构检验。
- **结果对应**：摘要、结论、主图题注的关键结论必须能在当前批次结果清单及来源文件找到，并在对应小节说明用途（登记以 `results/run_manifest.json` 为准）；禁编造数字、禁未运行图表。
- **匿名**：全文不得出现学校、赛区、姓名等身份信息。

## 十四、机器校验入口

- 生成层：`paper_format.new_document()`（样式注入 + 防重排）→ `pf.preflight_check(outline)` → 逐元素写入 → `save_document()`。
- 硬闸门（任一不过拒存）：`validate_paper_structure()` = 篇幅/排版 + 全黑字体 + 禁用词 + 三线表/方框表 + 公式密度 + **固定值行距含公式/图片拒存（`_clipped_object_issues`）** + **图片文件名规范（`_figure_filename_issues`）** + **参考文献年份（≥2016）**。
- 数值阈值单一来源：`contest_profile.py`（`CUMCM_*`、`REFERENCE_MIN_YEAR`）；行距常量：`paper_format.BODY_LINE_SPACING_PT`。

## 十五、LaTeX 源码版交付物（完整论文.tex）

- `save_document()` 在终态校验通过后、DOCX 发布前，由 `tools/docx/core/latex_export.export_latex_source` 从**同一内容快照**写出 `完整论文.tex`——先 tex 后 docx，两版内容不可能漂移；不编译、不产出 PDF、不要求本机有 LaTeX 环境。。`ctexart` 字体集**固定 `fontset=fandol`**（随 TeX Live 分发，Overleaf/本地 TeX Live 开箱可用，pdfLaTeX/XeLaTeX 皆可；勿用 windows 字体集——Overleaf 无 SimSun/SimHei）；推荐 XeLaTeX 编译。
- 结构映射（源码版只保证结构与内容一致，精细排版以 DOCX 交付版为准）：

| DOCX | LaTeX |
|---|---|
| 论文题目（黑体16pt居中） | `\documentclass[zihao=-4,a4paper]{ctexart}` + 文首题目段 |
| 一/二/三级标题 | `\section*`/`\subsection*`/`\subsubsection*`（保留"一、"编号文字） |
| 正文（宋体小四、缩进2字符、固定18磅） | `\linespread{1.5}` + `\parindent=2em` 近似；geometry 与 `setup_page` 边距一致 |
| 公式（equation() 写入的原始 LaTeX） | `\begin{equation}…\end{equation}`，**原样输出不转义**（侧通道 `record_equation_source`） |
| 图片 + 图题（`图N …`） | `\begin{figure}` + `\includegraphics{results/图片/<文件名>}` + `\caption*` |
| 表题 + 三线表 | `\caption*` + booktabs `tabular` |
| 附录A 支撑材料清单（三线表） | booktabs `tabular` |
| 参考文献（GB/T 7714，≥2016） | `thebibliography` + `\bibitem` |
| 关键词行 | `\noindent\textbf{关键词：}…` |

- 交付保护：`完整论文.tex` 与 `完整论文.docx` 同级列入清理器 `PROTECTED_ITEMS`，重跑随 DOCX 一同覆盖。
