# 假设与符号写作范式
> **用途**：指导论文第三章（模型假设）和第四章（符号说明）的写法。
> **依赖**：`文档/论文写作.md`
> **被引**：`文档/七轮自审框架.md`
---
## 一、模型假设

**篇幅**：按格式逐条编号，不做长段展开。

**格式**：
- "假设 N（短标题）：具体内容。"逐条编号
- 按题目需要一般 6–12 条
- 每条 1–2 句，写清内容与依据即可
- 禁止长段解释、研究意义、口号式合理性

**示例**：
```
假设 1（曲线贴合）：各把手中心始终位于给定曲线上，三维舞龙简化为一维曲线上的 224 个随动点。
假设 2（刚性弦长恒定）：相邻把手中心距离恒为 D_k=L_k-2e；这是刚体几何硬约束，弧长间距恒定只是其在缓变曲率下的近似。
假设 3（领队驱动）：龙头前把手沿切向匀速 v_h 运动，其余把手由链式约束被动确定。
```

## 二、符号说明

**篇幅**：三线表 ≥12 行（符号说明）。

**格式**：
- 三线表（符号说明）：符号(正体) | 含义 | 单位
- 符号使用前先定义：正文中每个符号首次出现即给定义（可直接引用符号表行），禁止未定义先使用
- 整表内容居中、符号不跨行
- 表前最多一句引入，表后不写任何说明段
- 符号说明与数学公式无关，禁止用公式/equation 注入

---

## 三、交付前核对

- [ ] 假设逐条编号，每条 1–2 句
- [ ] 假设数量 6–12 条
- [ ] 无长段解释或口号式合理性论述
- [ ] 符号说明表 ≥12 行
- [ ] 符号表整表居中、符号正体、不跨行
- [ ] 符号表前后无多余说明段
