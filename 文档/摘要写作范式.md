# 摘要写作范式（国赛中文摘要）

> **用途**：指导国赛中文摘要写法（四块内容范式）。
> **依赖**：`文档/论文写作.md`
> **被引**：`文档/七轮自审框架.md`

---

## 一、四块内容（不必生硬模板）

1. **问题对象**：研究什么，数据/约束从哪来
2. **方法与结果**：每子问题用什么方法，得什么数值结论
3. **检验或边界**：误差/灵敏度/稳健性/适用范围，至少给出一项真实检查
4. **关键词**：4–6 个，覆盖领域词和方法词

**不写**：章节安排、技术路线/组织结构、空泛价值判断（重要意义/表现良好）

---

## 二、篇幅版式

| 项目 | 要求 |
|---|---|
| 字数 | 800–900 字 |
| 篇幅 | 单独占第 1 页，不溢出 |
| 语言 | 只写中文，无英文翻译 |
| 图表 | 摘要不放图表 |
| 关键词 | 4–6 个，分号分隔 |

**按问题数量分配篇幅（硬规则）**：
- **2–3 问**：每问 2–3 句（方法 + 关键数字 + 结果解释），摘要总字数 800–900
- **4–5 问**：每问 1–2 句（方法 + 核心结果），摘要总字数 800–900
- **禁止**：平均用力、堆砌方法名、无数字支撑

**自检**：摘要须独占第 1 页、关键词后分页（正文首节从第 2 页起）；超页先压背景和方法铺陈，再补关键数字压回第 1 页。版面核验由 `validate_paper_structure` 统一执行。

## 三、句式怎么写

### 3.1 开头：直接进赛题对象，无"随着社会发展/近年来"铺垫

```text
城市外卖骑手调度面临订单高峰时延高、多区域任务不均衡和实时订单插入三个问题，本文按静态指派、协同分配、动态重调度三步求解。
```

### 3.2 方法与结果：每子问题方法名 + 数值结果紧挨，不单独铺方法原理

```text
0-1 指派模型和匈牙利算法把高峰期平均时延由 28.4 min 降至 16.7 min，降幅 41.2%。
改进遗传算法使总行驶里程较单区域策略减少 23.6%，骑手负载变异系数由 0.41 降至 0.18。
事件驱动重调度模型以 2 min 决策周期滚动更新，突发订单平均等待时间≤9.3 min，较固定周期缩短 31%。
```

### 3.3 检验收尾：写检查对象和具体数值，不写"模型鲁棒性良好"

```text
1000 次蒙特卡洛仿真中，订单到达率 ±20% 扰动时，系统平均时延变化 <5%。
```

## 四、常见问题速改

| 问题 | 处理 |
|---|---|
| 只有方法无结果 | 每问补一个具体数值 |
| 结果太虚（效果良好） | 换成对比/误差/最优值 |
| 背景太长 | 压到 1–2 句 |
| 句式全一样（针对问题一/二/三） | 变主语：第一问的约束方程…/第二问的优化结果…/第三问的外推区间… |
| 没检验 | 至少补一条误差/灵敏度/重采样结果 |
| 关键词太泛 | 用领域+方法组合 |
| 摘要超一页 | 先砍背景和方法原理，保结果数字 |

## 五、题型侧重点

| 题型 | 摘要突出 | 常见结果形式 |
|---|---|---|
| A（物理/工程） | 机理模型、推导依据、解析解/实测对比 | 相对误差、拟合优度、物理量数值 |
| B（优化/决策） | 目标函数、策略对比、最优值 | 最优目标值、提升%、收敛轮数 |
| C（数据/统计） | 特征工程、模型对比、精度指标 | AUC、准确率、RMSE、MAPE |
| D/E（综合） | 多方法融合、综合评价、灵敏度 | 综合得分、权重、参数区间 |

## 六、对比示例

**平庸**：针对外卖骑手调度问题，本文建立了调度优化模型。针对问题一用遗传算法，效果较好。问题二考虑多区域协同，模型表现良好。问题三引入动态因素，结果令人满意。做了检验证明可行。关键词：调度优化；遗传算法。

**较好**：城市外卖骑手调度面临订单高峰时延高、多区域任务不均衡和实时订单插入三个问题，本文按静态指派、协同分配、动态重调度三步求解。单区域静态调度以平均时延最小为目标，0-1 指派模型和匈牙利算法把高峰期平均时延由 28.4 min 降至 16.7 min，降幅 41.2%。多区域协同调度抽象为带容量约束车辆路径问题，改进遗传算法使总行驶里程减少 23.6%，骑手负载变异系数由 0.41 降至 0.18。实时订单按泊松到达，事件驱动重调度以 2 min 决策周期滚动更新，突发订单平均等待时间≤9.3 min，较固定周期缩短 31%。1000 次蒙特卡洛仿真中，订单到达率 ±20% 扰动时，系统平均时延变化 <5%。关键词：骑手调度；0-1 指派；改进遗传算法；车辆路径问题；动态重调度；蒙特卡洛仿真

> 优点：每问有数字、方法果贴近、结果递进、收尾给检验。

## 八、填空骨架（拿来即填）

> 写作时按此骨架逐段填充，写完后删除【】占位符。总字数 800–900，不超一页。

| 段 | 内容 | 字数 | 必含 |
|---|---|---|---|
| 1 | 问题对象 + 总方法 | 100–150 | 研究对象 + 核心难点 + 框架概述 |
| 2 | 各问方法与结果（按 §二 每问句数并入一段） | 450–600 | 每问方法名 + 模型类型 + **核心数值** |
| 3 | 检验/边界 + 特色收束 | 120–180 | 真实检查数据 + 一句推广 |

**模板**：

```
【第1段】针对【研究背景】中【核心难点1】、【核心难点2】等问题，本文建立了以【核心模型】为核心、融合【辅助方法1】与【辅助方法2】的【框架类型】框架。

【第2段】针对问题一，【简述方法】，构建了以【目标】为目标的【模型类型】模型，包含【约束1】、【约束2】等约束，求得最优【指标】为【具体数字】。针对问题二，引入【新增约束/因素】，修正了【关键方程】，重新求解后【指标】为【具体数字】，较问题一【变化】【百分比】%。针对问题三，针对【规模特征】设计了【双层/分层】框架：外层【方法】搜索【变量】，内层【方法】计算【目标】，求得【结果】为【具体数字】。

【第3段】对【关键参数/随机性】做【N】次【检验方式】，【指标】变化【具体数字】，验证模型在【扰动范围】内稳健。本文模型具有【特色】，可推广至【场景】。

关键词：【方法1】；【方法2】；【对象】；【目标】；【特色】
```

> 机器闸门 H1 只认三段：摘要标题→关键词之间正文段数必须恰为 3，故各问全部并入第 2 段（句内用句号/分号分开），检验并入第 3 段；禁止每问单开一段（6 段会被拒存，见 `文档/图片闸门配置与绘图规范.md`）。2–3 问时第 2 段每问 2–3 句，4–5 问时每问 1–2 句，总量仍 800–900 字。

**三条硬要求**：
1. 第 2 段每问至少一个**加粗具体数字**（LaTeX 用 `\res{数字}`），第 3 段检验给真实检查数据
2. 方法名必须出现（MILP / ARIMA / TOPSIS / K-means 等），不能只写"建立模型"
3. 关键词按"方法 → 对象 → 目标"排列，不用"数学建模；优化；模型"等空泛词
