# 综合代码规范

> **用途**：代码组织、命名、出图与清理规范。
> **依赖**：无
> **被引**：`文档/论文写作.md`、`知识库/建模增强/证据可复现审计.md`

编程手按赛题小问产出独立可运行入口 `Q<序号>.py`（如 `Q1.py`、`Q2.py`）；每个入口文件同时完成该问求解、结果落盘和出图。**通用核心算法与核心模型放 `solve_common.py`**（**解题专属**：只被 `Q<序号>.py` 入口复用，属解题代码一部分）；**统一生图配置放 `viz.py`**（配色/字号/尺寸/导出格式唯一入口，各问 import 调用，禁止各自另写绘图样式）。同一小问允许按需拆子模块（如 `Q3_仿真.py`/`Q3_优化.py`），但入口须能一键复现该问全部结果；纯理论/无需计算的小问可不写 `Q*.py`，在 `requirements.txt` 注明即可。**`files/`（赛题原件与原附录）只读：不修改、不重命名、不删除，填表类赛题只在 `results/数据/` 副本上填值且不得破坏原表结构（原行列、表头、合并单元格保持不变）**。

**命名铁律（两类分明）**：
- **解题代码** = `Q<序号>.py`（各问独立入口）+ `solve_common.py`（**可选**：仅当确有跨问复用的<u>通用核心算法/核心模型</u>——如公共几何/向量算子、共享读取与公式——才建这个文件；没有就不写，各问自包含）+ `viz.py`（**可选**：统一生图配置，各问只调用不各写）。`solve_common.py` **只放赛题本身的公共逻辑**，不是非解题文件的公共模块，也**绝不**放字体/颜色等样式配置、skill 工具调用、`SKILL_ROOT`/`sys.path`/机器绝对路径。中文字体在**用到该问的 Q 文件内就地设置**（`plt.rcParams`），绝不放进 `solve_common.py`。
- **非解答脚本** = 工具脚本、测试等，**一律不以 `Q` 开头**，且**完全自包含、不得依赖 `solve_common.py`、不得导入任何 skill 模块（`tools`/`docx`/`figure`/`mm_style` 等）**。

## 目录结构

```text

## 出图铁律（国赛图片必须全中文）

> 这是国赛。论文里**所有图片的文字（坐标轴、图例、标题、注释、单位）必须为中文**，

- **出图前必须在用到该问的 Q 文件内就地注册中文字体**（零 skill 依赖，copy 进脚本即可）：

  ```python
  plt.rcParams["font.sans-serif"] = ["SimHei", "Microsoft YaHei", "SimSun"]
  plt.rcParams["axes.unicode_minus"] = False
  plt.rcParams["figure.dpi"] = 300
  ```

  `SimHei` 打头保底中文黑体（与出图规范一致，优先消灭"中方块"），回落 Microsoft YaHei/宋体；`axes.unicode_minus=False` 保证负号不变方块；300 DPI 满足国赛出图要求。禁止把 `Arial` 放在 `SimSun`/`SimHei` 之前（会被 Arial 抢占导致中文变方块）。
- **禁止 import skill 的字体模块**：不得 `import mm_style` / `tools.*`，也不得调用 `configure_chinese_style()`——那是 skill 内部出图函数（`tools/figure/templates/mm_style.py`），别人拿到赛题目录没装 skill 就会报错，破坏可复现性。且 `configure_chinese_style` 还会顺带改 DPI/轴线/图例等全局样式，赛题代码应按需用上面的 3 行手配。此约束由 `tools/common/reproducibility.py` 守护：硬闸门遇 `configure_chinese_style()` 或 `tools.*`/`mm_style` import 会在交付时自动整行清扫后再存，若清扫后仍残留则拒存兜底。
- 所有可见标签写中文；`RMSE`/`AUC`/`R²`/单位（`°C`/`m`/`s`）等通用缩写可保留，但轴名应为中文，
  如 `均方根误差 (RMSE)`、`温度 (°C)`。
- 禁止中英文混排；禁止图里出现 `False Positive Rate`、`Standard Deviation`、`Observed` 等英文。
- 出图统一复用 `tools/figure/templates/` 下的绘图模板，保证字体/配色/DPI 一致；**复制模板代码内联到 Q 文件即可，不得在赛题代码里 `import` skill 的模板模块**。
- 交付前可跑 `python tools/figure/runtime/audit_figures.py <代码目录>` 自检字体与残留英文标签。
- **论文正文（docx 层）字体约定**（由 `tools/docx/core/paper_format.py` 排版，随文档生成，非赛题代码内设置）：中文正文宋体、标题黑体、正文内英文/数字 Times New Roman、公式 Cambria Math，全部纯黑（2026 口径：代码不入论文附录，无附录代码字体）。

## 输出规范

- **允许简短结果摘要输出**：每个 `Q<序号>.py` 可以在命令行输出本问最终的 2–6 行关键结果（如最优值、误差、方案编号和单位），便于运行时确认；禁止输出进度、调试信息、整表数据或重复日志。
- 结果摘要必须与 `results/数据/` 和 `results/论文评审与分析.md` 中的数值一致；详细解释只写入该合并文档。
- 所有结果落盘到 `PROJECT_ROOT/results/`：
  - `数据/`：csv、xlsx、模型参数、预测结果、指标（一律不用 JSON）。
  - `图片/`：高清图（预测曲线 / 误差图 / 残差图 / 收敛曲线 / 方案对比 / 指标排名 / 权重分析…）。
- 结果文件与图片直接写入 `results/数据/` 和 `results/图片/`，不再按 run 隔离；重跑覆盖当前结果。
- **结果文件格式（W8 预警强制）**：解题过程产生的数据文件一律不用 JSON——数据佐证优先 xlsx（Excel 可读、多表带格式）或 csv；csv 必须 `utf-8-sig` 编码（带 BOM，`to_csv(..., encoding="utf-8-sig")`），否则 Excel 直接打开乱码。工具链登记落白名单数据文件 `spss_outputs.csv`、`文献检索.csv`（表格型 csv/xlsx，文本型用 md）。`results/run_manifest.json` 是运行登记索引、不属于 `results/数据/` 数据文件。

- **全部 W 级软预警总表（不拒存，收尾必须清零）**：W1 结果分析不重复插图（同图换题注）｜W2 公式前缺解释｜W3 流程图题注不笼统（须含本题内容）｜W4 公式用 OMML 非图片｜W5 出图中文正常（SimHei 打头）｜W6 画图坑（双Y轴/饼图/jet/裸legend/loc='best'，对照 `tools/figure/references/画图避坑清单.md`）｜W8 数据文件格式（csv 缺 UTF-8-SIG/数据文件用了 json）｜W9 图表缺前置引出｜W10 图表上下文（前引导 + 后 ≥15 字解释）｜W11 章节字数超/欠预算（±20%）。W 编号与判法以 `structure_validation.py` 注释链及 `文档/图片闸门配置与绘图规范.md` §3 为真源。

```python
def save_results_xlsx(out, xlsx_path):
    import pandas as pd
    sheets, used = {}, set()
    def sheet(name, obj):
        name = str(name)[:31] or "sheet"; base, k = name, 2
        while name in used: name = f"{base[:28]}_{k}"; k += 1
        used.add(name)
        df = pd.DataFrame(list(obj.items()), columns=["指标", "数值"]) if isinstance(obj, dict) else pd.DataFrame(obj)
        df.to_excel(_writer, sheet_name=name, index=False)
    scalars, nested = {}, {}
    def flat(prefix, obj):
        for key, val in obj.items():
            full = f"{prefix}·{key}" if prefix else str(key)
            if isinstance(val, dict) and all(not isinstance(x, (dict, list)) for x in val.values()):
                scalars.update({f"{full}·{k2}": v2 for k2, v2 in val.items()})
            elif isinstance(val, (dict, list)) or (isinstance(val, list) and any(isinstance(x, (dict, list)) for x in val)):
                nested[full] = val
            elif isinstance(val, list):
                scalars[full] = ", ".join(map(str, val))
            else:
                scalars[full] = val
    flat("", out)
    global _writer
    with pd.ExcelWriter(xlsx_path, engine="openpyxl") as _writer:
        if scalars: sheet("概览", scalars)
        for name, obj in nested.items(): sheet(name, obj)

## 性能规范（数值求解 + 出图）

国赛建模常涉及大量重复计算与数值积分，代码必须在合理时间内跑完（建议单问求解 ≤ 2 分钟，全文 ≤ 10 分钟）；同时每问的"求解"与"出图"应**一次完成**，避免分开跑两遍导致时间翻倍、且图文数值易不一致。

### 1. 数值求解性能

- **向量化优先**：能用 NumPy 向量化/矩阵运算的，禁止写 Python 级 `for` 循环逐点计算；参数扫描用 `np.meshgrid` + 广播。
- **固定步长 RK4 / 受控自适应**：常微分方程积分统一用固定步长四阶 Runge-Kutta（或 `scipy.integrate.solve_ivp` 时固定 `max_step` 并设 `rtol/atol`），避免纯自适应步长带来的不可复现与抖动。
- **解缓存复用**：同一物理/优化问题在不同问中复用时，结果写入 `results/数据/*.csv`（或 xlsx）后读取复用，禁止每个子问重新从头求解。
- **瓶颈提速**：碰撞/优化内层循环可用 `numba`(`@njit`) 或预计算查表（lookup table）替代在线重算。
- **零冗余输出**：求解过程禁止 `print` 进度/中间值；仅保留最终结果摘要。调试日志写入 `results/` 或使用 `logging`，不得污染标准输出。

### 2. 计算 + 绘图一体（每问单文件模式）

每问的 建模 → 数值求解 → 保存结果 → 出图，放在**同一段逻辑里一气呵成**，**不要**把"算"和"画"拆成 `compute.py` + `plot.py` 两个脚本分开跑：

- 在对应 `Q<序号>.py` 内完成"求解 + 出中文图 + 落盘结果数据"，调用一次即得图与数据。
- 每次运行将图片和数值写入 `results/图片/` 与 `results/数据/`；**图片与数据文件一律中文命名**（如 `2_Q1_匹配指数对比.png`、`Q1_匹配指数.csv`），不用英文/拼音缩写（`fig_q1.png`、`data_q1.csv` 均不合格）；**命名细则唯一权威见 `文档/样式统一规定.md` §六（图片带全局序号、表/数据文件不带），此处只给示例、不重复细则**；数值结果（最优参数、指标、误差）写入结果文件后，调用 `tools.docx.core.result_contract.write_run_manifest()` 生成 `results/run_manifest.json`；**时间窗约定**：`RUN_STARTED` 在 Step 6 开跑时记录一次（存 `solve_common.py`），各 Q 脚本统一传 `write_run_manifest(started_at=RUN_STARTED, completed_at=现在)`——时间窗必须覆盖全部登记产物的 mtime，否则溯源闸门报"修改时间不在本次运行区间"（多脚本顺序执行的级联事故），并同时传入 `manual_stats=load_spss_outputs(project)` 把 SPSS 等人工工具结果一并登记（SPSS 结果是一等公民真结果，非参考）。论文只允许读取当前清单登记的结果，禁止从代码或旧目录凭上下文抄参数。
- **三线表表头须为中文（硬闸门强制）**：正文三线表的第一行（表头）用中文表头，禁止 `term/coef/se/OR_lo/comp/direction` 这类纯英文表头；可保留 `OR/CI/AUC/R²/p/F` 等通用数学/统计缩写（`符号列` 属符号说明表不计入）。交付时 `validate_paper_structure` 会拒存正文英文表头（见 `tools/docx/core/structure_validation.py::_table_header_language_issues`）；附录表为附录A 支撑材料清单（三线表），缺表线拒。
- **图片文件名（硬闸门强制）**：统一格式 `<全局序号>_<描述>.png`，全局序号全库递增不得重复；禁止「图N」开头、纯英文/拼音缩写段。缺序号、序号重复、含非法片段即拒存（`_figure_filename_issues`）；**命名规则唯一权威见 `文档/样式统一规定.md` §六**，此处不重复细则。
- 对摘要、结论或主图引用的关键数值，保留其对应的结果数据文件（csv/xlsx，不用 json）、生成代码和图片文件；在 `results/论文评审与分析.md` 标明结果文件与图表的对应关系。
- 运行器按 `Q<序号>.py` 顺序执行；若问题庞大确需拆子模块，子模块内部同样遵循"算完即画图"，不要跨文件分两遍跑。

### 3. 性能自检

- 在 `requirements.txt` 标注预计总运行时间；某问 > 2 分钟须说明原因或给出向量化/缓存版本。
- 对每个 `Q<序号>.py` 实测，确保复现环境能跑通，并记录运行顺序。

## 视觉风格红线（必须执行）

`code/` 下所有解题/出图/出数脚本默认执行以下极简代码面要求：

- **禁止 `"""..."""` 三引号 docstring**：模块顶部、函数顶部均不得出现。
- **禁止横幅/分隔线装饰注释**：形如 `# ---...---`、`# ======` 等装饰性横线注释一律删除。
- **禁止 Markdown 列表、大段实现说明、无关规则清单**：代码里不写与运行无关的说明性文字。
- **禁止连续空行（最多 1 行）**：函数之间、逻辑块之间用紧凑的单空行或不留空行。
- **禁止调试/进度 `print`**：`print('正在计算…')`、`print('done')` 等裸字符串状态打印一律禁止；仅最终 2–6 行关键结果可用变量/格式化输出。

## 质量红线

- 代码真实可运行，`requirements.txt` 足以复现。
- 固定随机种子，结果可复现。
- 不编造数据；缺失数据须显式说明处理方式（插值 / 剔除 / 建模补全）。
- 异常处理到位，关键步骤有简要注释（解释"为什么"，不是"做了什么"）。
- 各 `Q<序号>.py` 让用户一条命令就能跑出该问全部结果与图。

## 失败恢复链（运行出错时按此分级处理，不盲目重试）

| 错误类型 | 判定信号 | 恢复动作 | 重试上限 |
|---|---|---|---|
| **E1 环境错误** | ImportError / FileNotFoundError / 权限拒绝 / 路径不存在 | 修环境/路径/安装依赖，原地重跑 | 不计入重试上限 |
| **E2 代码错误** | SyntaxError / TypeError / 维度不匹配 / IndexError / KeyError | 定位根因→修复代码→重跑 | 单问最多 3 次 |
| **E3 结果异常** | 跑通但结果不合理（量级荒谬/全零/约束全违例/目标函数发散） | 不修改代码，按下方诊断链排查 | 诊断链走完仍不通过→回 Step 4 换候选模型 |
| **E4 超时** | 单问代码运行超过 3 分钟仍未结束 | 立即终止，不等待；回 Step 4 换更轻量的算法（降复杂度/换近似/减迭代） | 同算法不允许第二次超时 |

**E3 诊断链（按顺序逐项排查，不跳步）**：
1. 检查数据：量级/单位/缺失值/异常值/行列数是否符合预期；
2. 检查约束：是否过紧（可行域为空）或矛盾（互斥约束）；
3. 检查模型假设：数据是否违反前提条件（如非正态用了参数检验、非平稳用了 ARIMA）；
4. 检查参数：初值/步长/迭代上限/正则化系数是否合理；
5. 以上均无法修复 → 记录失败原因，回 Step 4 选择备选模型（Model Contract 的 fallback 字段）。

## 结果健全性检查（每个 Q 运行通过后、进入可视化前必须完成）

1. **数据维度**：原始 N 行 → 处理后 M 行，M≤N 且无意外丢失；
2. **量级合理**：目标函数值/关键指标不在 10⁻³⁰⁰ 或 10³⁰⁰ 量级；
3. **约束满足**：所有约束最大违反 < 1e-6；
4. **基线对比**：至少优于 sanity baseline（或说明为何不优于它的合理原因）；
5. **物理意义**：结果能用一句话解释其实际含义；
6. **稳定性**：换随机种子重跑一次，关键指标波动 < 10%（确定性模型跳过此项）。

健全性检查不通过的结果**不得进入 Tournament 评分**，不得写入 run_manifest，不得写入论文。
