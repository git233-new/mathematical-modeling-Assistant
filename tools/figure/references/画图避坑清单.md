# 画图避坑清单（18 条）

> 蒸馏自 scipilot-figure-skill viz_pitfalls。每条：错误 → 为什么错 → 正确做法。
> 标 **[W]** 的可被机器预警（`_plot_pitfall_warnings`，W 级不拒存但必须人工确认或改写）；
> 标 **[闸门]** 的已有硬/软闸门覆盖。渲染后自检（缺字/裁切/遮盖）见现有 `runtime/audit_figures.py` 与 `validate_figure.py`。

| # | 坑 | 为什么错 | 正确做法 |
|---|---|---|---|
| P1 | 裸均值柱掩盖分布 | n=3 与 n=300 画得一样高；双峰/偏态/离群被均值吃掉 | n≥10 箱线/小提琴+叠加原始点；n<10 直接点图 |
| P2 | 双 Y 轴 **[W]** | 两轴尺度可任意调，"重合/分歧"是作图者捏造 | 同量纲共轴；异量纲用散点（x=var1,y=var2）或上下双子图共 x |
| P3 | 饼图/3D 图 **[W]** | 人眼辨长度比辨角度准 3 倍；3D 视角扭曲数值 | 占比→横向柱状（按值排序）；构成→堆叠柱状；3D 数据→2D 热力图 |
| P4 | Y 轴不当截断 | 非 0 起点让小差异看着像翻倍 | 比例/概率从 0 起；跨数量级用 log；必须截断画断裂标记并图注说明 |
| P5 | 连续色阶无 colorbar | 读者无法知道颜色对应数值 | 颜色映射数值的图必配带标签（变量+单位）的 colorbar；多图对比锁 vmin/vmax |
| P6 | 离散点连折线 | 折线暗示不存在的连续趋势 | 分类轴改分组散点/柱状；只有真正有序的 x 才连线 |
| P7 | 过度用色 | 颜色 >6 种不可辨 | 颜色 3-5 种；多余维度用 marker/线型/分面 |
| P8 | 图例缺失/不清 | 读者要反复来回查 | 线末端直接标名；或图例完整覆盖所有线/色 |
| P9 | 误差类型不交代 | SD/SEM/CI 含义完全不同 | 图注写清误差类型与 n |
| P10 | 过度装饰 | 网格/阴影/3D 效果干扰读数 | 去掉与数据无关的视觉元素 |
| P11 | 分辨率/格式不达标 **[闸门]** | 印刷模糊 | dpi≥300 PNG（现有闸门强制），矢量图更佳 |
| P12 | 一图多论点 | 读者抓不住重点 | 一图一论点；其余拆图 |
| P13 | 红绿对比/不做色盲检查 | 色盲读者不可读 | 色盲安全配色（viridis 系/RdBu）；形状+颜色冗余编码 |
| P14 | rainbow/jet 色图 **[W]** | 感知不均匀，虚假边界 | viridis/magma/cividis；双向数据 RdBu_r+center=0 |
| P15 | 显著性符号滥用 | * / ** / ns 含义不清 | 图注定义标记与检验方法；只标有检验支撑的 |
| P16 | 中文/负号变方框 **[闸门]** | SimHei 未注册、axes.unicode_minus 缺失 | 脚本开头注册 SimHei 打头 + `axes.unicode_minus=False`（代码规范强制） |
| P17 | 文字裁切/图例遮盖 **[闸门]** | 导出后暴露 | `bbox_inches='tight'`/constrained_layout；渲染后跑 `audit_figures.py` 自检 |
| P18 | 多面板编号错乱 | (a)(b)(c) 与题注/引用脱节 | 面板编号与正文引用一一对应；复杂多面板非必要不用 |

**使用时机**：出图前按 P1-P9 设计（选图时避开）；出图后按 P10-P18 自检。机器预警只覆盖 **[W]** 三项与 **[闸门]** 各项，其余靠本清单人工对照。
