# 数据可视化指南

本指南提供数学建模论文中常用图表的代码模板，包括Python和Matlab两种实现。

## 0. 画图前数据剖析（先看数据再选图）

动笔前对目标数据做 4 项快查（人工即可，无需跑脚本）：

| 查什么 | 怎么判 | 画图含义 |
|---|---|---|
| 列类型 | 连续（唯一值>7/含小数）、有序整数（≤7 个唯一值）、分类（object 且类别<30）、时间（可解析日期） | 连续做 y/散点；有序整数别连折线；分类走 x/hue；时间走折线 x |
| 样本量 | 每组 n：≥30 / 10-30 / 3-10 / <3 | 决定箱线/柱状/直接点图（阈值见 `图表选型与论证.md` 决策三轴） |
| 分组结构 | 分组最小/最大样本量是否悬殊 | 悬殊组对比要叠加原始点，不能只看均值 |
| 缺失/异常 | 缺失率、离群点 | 异常值在图上要可见（箱线 fliers），不可悄悄剔除 |

选图决策走 `图表选型与论证.md`（决策三轴 + 速查表）；避坑对照 `画图避坑清单.md`。

## 1. 折线图

### Python实现
```python
import matplotlib.pyplot as plt
import numpy as np

# 设置中文字体
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)

plt.figure(figsize=(10, 6))
plt.plot(x, y1, 'b-', linewidth=2, label='sin(x)')
plt.plot(x, y2, 'r--', linewidth=2, label='cos(x)')

plt.xlabel('X轴标签', fontsize=12)
plt.ylabel('Y轴标签', fontsize=12)
plt.title('标题', fontsize=14)
plt.legend(loc='best')
plt.grid(True, linestyle='--', alpha=0.7)
plt.tight_layout()
plt.savefig('line_plot.png', dpi=300, bbox_inches='tight')
plt.show()
```

### Matlab实现
```matlab
x = linspace(0, 10, 100);
y1 = sin(x);
y2 = cos(x);

figure;
plot(x, y1, 'b-', 'LineWidth', 2);
hold on;

ylabel('Y轴标签');
title('标题');
legend('sin(x)', 'cos(x)');

hold off;
```

## 2. 柱状图

### Python实现
```python
import matplotlib.pyplot as plt
import numpy as np

categories = ['类别A', '类别B', '类别C', '类别D']
values1 = [23, 45, 56, 78]
values2 = [35, 52, 43, 65]

x = np.arange(len(categories))
width = 0.35

fig, ax = plt.subplots(figsize=(10, 6))
bars1 = ax.bar(x - width/2, values1, width, label='组1', color='steelblue')
bars2 = ax.bar(x + width/2, values2, width, label='组2', color='coral')

ax.set_xlabel('类别', fontsize=12)
ax.set_ylabel('数值', fontsize=12)
ax.set_title('柱状图标题', fontsize=14)
ax.set_xticks(x)
ax.set_xticklabels(categories)
ax.legend()
ax.grid(axis='y', linestyle='--', alpha=0.7)

for bar in bars1:
    height = bar.get_height()
    ax.annotate(f'{height}',
                xy=(bar.get_x() + bar.get_width() / 2, height),
                xytext=(0, 3), textcoords="offset points",
                ha='center', va='bottom')

plt.tight_layout()
plt.savefig('bar_plot.png', dpi=300, bbox_inches='tight')
plt.show()
```

### Matlab实现
```matlab
categories = {'类别A', '类别B', '类别C', '类别D'};
values1 = [23, 45, 56, 78];
values2 = [35, 52, 43, 65];

figure;
bar([values1; values2]);
set(gca, 'XTickLabel', categories);
xlabel('类别');
ylabel('数值');
title('柱状图标题');

grid on;
saveas(gcf, 'bar_plot.png');
```

## 3. 散点图

### Python实现
```python
import matplotlib.pyplot as plt
import numpy as np

np.random.seed(42)
x = np.random.randn(100)
y = x + np.random.randn(100) * 0.5

plt.figure(figsize=(10, 6))
plt.scatter(x, y, c='blue', alpha=0.6, edgecolors='black', linewidth=0.5)

plt.xlabel('X轴标签', fontsize=12)
plt.ylabel('Y轴标签', fontsize=12)
plt.title('散点图标题', fontsize=14)
plt.grid(True, linestyle='--', alpha=0.7)

z = np.polyfit(x, y, 1)
p = np.poly1d(z)
plt.plot(x, p(x), "r--", linewidth=2, label=f'拟合直线: y={z[0]:.2f}x+{z[1]:.2f}')
plt.legend()

plt.tight_layout()
plt.savefig('scatter_plot.png', dpi=300, bbox_inches='tight')
plt.show()
```

### Matlab实现
```matlab
x = randn(100, 1);
y = x + randn(100, 1) * 0.5;

figure;
scatter(x, y, 'filled');

xlabel('X轴标签');
ylabel('Y轴标签');
title('散点图标题');
grid on;

p = polyfit(x, y, 1);
x_fit = linspace(min(x), max(x), 100);
y_fit = polyval(p, x_fit);
hold on;
plot(x_fit, y_fit, 'r--', 'LineWidth', 2);
legend('数据点', sprintf('拟合直线: y=%.2fx+%.2f', p(1), p(2)));
hold off;

saveas(gcf, 'scatter_plot.png');
```

## 4. 饼图（不推荐，仅存实现备查）

> **警示**：人眼辨长度比辨角度准 3 倍，饼图本质上不可读；类别>5 配色不够；3D 饼图更不可用。
> 占比展示首选**横向柱状图（按值排序）**，构成分解用**堆叠柱状**（见 `画图避坑清单.md` P3）。
> 以下实现仅当赛题明确要求饼图样式时使用。

### Python实现
```python
import matplotlib.pyplot as plt

labels = ['A类', 'B类', 'C类', 'D类']
sizes = [25, 35, 20, 20]
explode = (0, 0.1, 0, 0)
colors = ['#ff9999', '#66b3ff', '#99ff99', '#ffcc99']

plt.figure(figsize=(8, 8))
plt.pie(sizes, explode=explode, labels=labels, colors=colors,
        autopct='%1.1f%%', shadow=True, startangle=90)
plt.axis('equal')
plt.title('饼图标题', fontsize=14)
plt.savefig('pie_chart.png', dpi=300, bbox_inches='tight')
plt.show()
```

## 5. 热力图

### Python实现
```python
import matplotlib.pyplot as plt
import numpy as np

data = np.random.rand(10, 10)
labels = [f'变量{i+1}' for i in range(10)]

fig, ax = plt.subplots(figsize=(10, 8))
im = ax.imshow(data, cmap='YlOrRd')

ax.set_xticks(np.arange(10))
ax.set_yticks(np.arange(10))
ax.set_xticklabels(labels)
ax.set_yticklabels(labels)

plt.setp(ax.get_xticklabels(), rotation=45, ha="right", rotation_mode="anchor")

for i in range(10):
    for j in range(10):
        text = ax.text(j, i, f'{data[i, j]:.2f}',
                       ha="center", va="center", color="black", fontsize=8)

fig.colorbar(im, ax=ax)
plt.title('热力图标题', fontsize=14)
plt.tight_layout()
plt.savefig('heatmap.png', dpi=300, bbox_inches='tight')
plt.show()
```

### Matlab实现

## 7. 子图布局

```python
import matplotlib.pyplot as plt
```

## 8. 3D图

### Python实现
```python
import matplotlib.pyplot as plt
import numpy as np
from mpl_toolkits.mplot3d import Axes3D

fig = plt.figure(figsize=(10, 8))
ax = fig.add_subplot(111, projection='3d')

x = np.arange(-5, 5, 0.25)
y = np.arange(-5, 5, 0.25)
X, Y = np.meshgrid(x, y)
Z = np.sin(np.sqrt(X**2 + Y**2))

surf = ax.plot_surface(X, Y, Z, cmap='viridis', edgecolor='none', alpha=0.8)

ax.set_xlabel('X轴')
ax.set_ylabel('Y轴')
ax.set_zlabel('Z轴')
ax.set_title('3D表面图')

fig.colorbar(surf, ax=ax, shrink=0.5, aspect=5)
plt.savefig('3d_plot.png', dpi=300, bbox_inches='tight')
plt.show()
```

### Matlab实现

## 10. 箱线图

### Python实现
```python
import matplotlib.pyplot as plt
import numpy as np

data = [np.random.normal(0, 1, 100),
        np.random.normal(3, 1, 100),
        np.random.normal(1.5, 1.5, 100)]

fig, ax = plt.subplots(figsize=(10, 6))
bp = ax.boxplot(data, labels=['组1', '组2', '组3'], patch_artist=True)

colors = ['#ff9999', '#66b3ff', '#99ff99']
for patch, color in zip(bp['boxes'], colors):
    patch.set_facecolor(color)

ax.set_xlabel('组别', fontsize=12)
ax.set_ylabel('数值', fontsize=12)
ax.set_title('箱线图标题', fontsize=14)
ax.grid(axis='y', linestyle='--', alpha=0.7)
plt.tight_layout()
plt.savefig('boxplot.png', dpi=300, bbox_inches='tight')
plt.show()
```

### Matlab实现

## 子图标注与图例摆放（防遮挡铁律）

一图多子图（对比/组合）时：

1. **每个子图必须有外侧标注**——(a)(b)(c) 或中文短标题，放在子图**正上方或正下方**（图形区域之外），正文引用写"图N(a)"。标注绝不压在图形上；不要写"上图/下图"这类相对指代。
2. **图例一律放图外**，两个方向任选：
   - 下侧横排：`ax.legend(loc='upper center', bbox_to_anchor=(0.5, -0.12), ncol=按项数)`
   - 右侧竖排：`ax.legend(loc='center left', bbox_to_anchor=(1.02, 0.5))`
   - 禁止 `plt.legend()` 裸调用与 `loc='best'`（默认在图内，必然压数据，W6 预警）。
3. **画面内标注只留紧贴数据点的必要文字**（如峰值数值、拐点标签），且不得与任何线/点/文字重叠；其余说明全部移到图例或题注。
4. 组合图用 `constrained_layout=True` 或 `tight_layout()` 防外置标注被裁切；导出前跑 `audit_figures.py`。

```python
fig, axes = plt.subplots(1, 2, figsize=(10, 4), constrained_layout=True)
axes[0].set_title('(a) 预测值与真实值对比', loc='left')   # 子图外侧标注
axes[1].set_title('(b) 误差分布', loc='left')
axes[0].legend(loc='upper center', bbox_to_anchor=(0.5, -0.18), ncol=2)  # 下侧横排
```

## 图表设计原则

### 1. 清晰性
- 图表应清晰展示数据
- 避免过多的装饰元素
- 标注应完整、准确

### 2. 美观性
- 选择合适的颜色搭配
- 保持图表比例协调
- 注意留白和布局

### 3. 准确性
- 数据应真实可靠
- 坐标轴刻度应合理
- 避免误导性的可视化

### 4. 完整性
- 应包含标题
- 应标注坐标轴名称和单位
- 应有图例（如适用）
- 多图应有统一编号

### 5. 格式要求
- 分辨率不低于300 DPI
- 推荐使用PNG或PDF格式
- 图表尺寸应适合论文排版
