# 图表选型与论证（决策框架 + 模板目录）

> 分工：本文件管"**画什么图、为什么**"；执行与闸门数值唯一权威见 `文档/图片闸门配置与绘图规范.md`；
> 出图代码红线见 `文档/代码规范.md`；避坑细节见 `画图避坑清单.md`。
> 每个模板 id 对应 `templates/` 下可运行脚本，渲染统一走 `tools/figure/runtime/render_template.py`。

## 一、决策三轴（画图前必答）

1. **变量结构**：1×连续看分布｜1×分类看占比｜分类+连续看组间比较｜2×连续看关系｜时间+连续看趋势｜多连续看相关｜二维矩阵看模式｜嵌套分组看层次。
2. **论证意图**（最易忽略——同一批数据，论点不同图就不同）：分布→直方图/KDE/箱线；比较→箱线/带误差柱状/小提琴；关系→散点+回归；趋势→折线+误差带；构成→堆叠柱状（**不要饼图**）；相关→热力图/pairplot；差异→箱线+显著性标注；不确定性→误差棒/置信带。
3. **数据规模**：每组 n≥30 三者皆可；10≤n<30 优先箱线/小提琴，柱状必须叠加原始点；3≤n<10 强烈建议直接散点；n<3 不要画统计图，直接列点；总数 >10⁴ 散点加 alpha=0.1-0.3 或改 hexbin。

## 二、数据形态 → 图型速查

| 数据形态 | 首选 | 备选 | 不该用 |
|---|---|---|---|
| 单连续看分布 | KDE/直方图 | 箱线/小提琴 | 饼图/折线 |
| 单分类看占比 | 横向柱状（按值排序） | 堆叠柱状 | **饼图** |
| 分类 vs 连续（n≥10/组） | 箱线 + 原始点叠加 | 小提琴/带误差柱 | 仅均值柱 |
| 分类 vs 连续（n<10/组） | stripplot/点图 | — | 箱线/均值柱 |
| 2 连续 | 散点+回归线 | hexbin（大样本） | 折线（x 非有序时） |
| 时间 vs 连续 | 折线+误差带 | 阶梯图 | 柱状 |
| 多连续（3-20） | 相关性热力图 | pairplot | 平行坐标 |
| 矩阵数据 | 热力图（感知均匀色图） | 表格 | 3D 表面 |
| 构成 | 堆叠柱状 | 100% 堆叠柱 | **饼图/3D** |
| 二分类性能 | ROC/PR 曲线 | 混淆矩阵热力图 | 仅准确率柱状 |

色图：单向数据 `viridis`/`magma`/`cividis`；双向 `RdBu_r`+`center=0`；**永远不用 rainbow/jet/hsv**；连续色阶必须配带标签的 colorbar。

## 三、同一批数据，不同论点 → 不同图

示例：30 受试者 × 2 药 × 5 时间点。

| 论点 | 图 |
|---|---|
| "A 整体快于 B" | 箱线（x=药物，压平时间） |
| "A/B 在 t=3 分歧最大" | 折线（x=time，hue=药物）+误差带 |
| "个体差异极大" | spaghetti plot + 粗均线 |
| "t=3 显著不同" | 配对箱线 + 显著性桥（只做 t=3） |

动笔前先写一句话："这张图要说服读者相信什么"，再按上表定图。

## 四、何时拆图（复杂度上限）

任一命中即拆：维度组合 >12 panel；x 轴分类 >8 标签要 45° 旋转；图例 >6 项；y 轴跨数量级又不能用 log；一张图想说两件事。**拆图策略**：按分组维度拆 / 按 panel 拆 / 按论点拆；主图只放核心结论。多维度映射通道容量：x 轴 5-10 类、颜色 3-5、marker 2-3、子图 2-8——超乘积即拆。

## 五、语义边界

- **折线 vs 散点**：点间有连续关系才连线（时间/剂量/序列）；分类轴连线暗示不存在的趋势。
- **柱状 vs 箱线**：柱状看均值±误差（假设单峰近高斯，n≥30）；箱线看中位数+四分位（不假设，n≥10）；n 小或分布未知默认箱线；两者最佳实践都是**叠加原始点**。
- **热力图 vs 散点矩阵**：>8 变量用热力图；2-8 变量 pairplot 看分布更丰富。
