# Nature-inspired 图件契约

本文件是 `figure` 的科研图优化规范，不是独立绘图技能或第二套运行链。
实际绘图统一使用上级 `runtime/` 与 `templates/`；质量门禁只检查样式、
导出、数据完整性风险和最终尺寸可读性，不替代统计复核。

本契约把 Nature-inspired 图件的有效做法接入本项目。它是**国赛中文图表的出版级增强层**，不是对某个期刊当前投稿规则的承诺；目标期刊有额外要求时，以目标期刊官方文件为准。

## 绘图前五项

每张图先写清以下内容，再开始调颜色和布局：

1. **核心结论**：这张图要证明的一句话。
2. **证据链**：每个面板只承担一个问题；重复表达的面板合并或删除。
3. **图件原型**：定量网格、示意图主导组合、图像板+定量、非对称混合图。
4. **数据契约**：输入字段、单位、分组顺序、重复单位、不确定性定义。
5. **导出契约**：最终尺寸、中文字体、最小字号、SVG/PDF 可编辑文字、PNG/TIFF 分辨率和 source data。

## 默认视觉立场

- 一个主证据面板 + 若干从属验证面板，不把所有子图做成同等重量。
- 每张图使用一个主色族、一个中性基线和少量方向性强调色。
- 主模型、基线、改进量角色固定；不要跨面板随意换色。
- 直接标注优先于远距离图例；旋转文字使用锚定布局。
- 统计量、`n`、误差线定义、数据来源和图像完整性说明属于图件证据，不是事后装饰。
- 最终必须按论文实际物理尺寸逐面板检查遮挡、裁切、字号、图例间距和主次层级。

## 数据完整性

- 默认使用全部观测和要求变量，不为美观静默抽样。
- 删除行/列/类别时，记录规则、删除前后数量和理由。
- 对数、比值、插值、KDE、相关性等变换必须有边界检查。
- 配对数据优先展示配对差异；多折/多种子结果必须给出一致的不确定性定义。
- 模拟数据只能用于模板演示，不能混入真实交付图。

## 项目内预检

```bash
python tools/figure/runtime/validate_figure.py <绘图脚本.py>
python tools/figure/runtime/audit_figures.py <代码目录>
python tools/figure/runtime/audit_pdf_text.py <图件.pdf> --min-pt 5
```

三项都是预检，不替代统计复核和最终视觉检查。现有模板继续使用 `mm_style.save_panel()` 输出 PNG/PDF/SVG；需要投稿 TIFF 或自定义格式时使用 `mm_style.finalize_figure()`。
