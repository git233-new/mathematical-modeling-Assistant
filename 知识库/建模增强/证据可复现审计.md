# 证据可复现审计（Evidence & Reproducibility Audit）

> **用途**：确保论文每个重要结论可追溯到可核验证据，所有数值可在 `results/` 复现。
> **依赖**：`SKILL.md`（铁律 5/8）、`文档/代码规范.md`
> **被引**：`知识库/建模增强/冠军挑战者建模流程.md`

---

## 1. 证据类别与锚定方式

| 证据类别 | 在论文中如何锚定 |
|---|---|
| 数据 | 来源附件、预处理脚本、行数/字段 |
| 代码 | 脚本文件名 + 关键函数 |
| 结果表 | 引用 `results/数据/xxx.csv` 的具体行列 |
| 图 | 图号 + 数据来源文件 |
| 公式 | 符号定义与假设，推导链完整 |
| 文献 | 引用编号，结论与文献主张一致 |

**映射规则**：论文每个"结论性数字"旁应有可追溯标记，如：
> 冠军测试集 RMSE=0.99（见 `results/数据/nn_test_metrics.csv`，种子=42，5 次均值）。

---

## 2. 结果三态管理（核心）

| 状态 | 定义 | 能否进正式论文 |
|---|---|---|
| **探索结果** | 调参、试跑、方法筛选期数值（冠军—挑战者对抗中） | 否，仅内部看 |
| **验证结果** | 固定协议下公平对比的数值 | 仅作对比表中间行 |
| **最终冻结结果** | 冠军冻结后在测试集/正式数据上的报告值 | **是，论文唯一采信来源** |

**铁律**：
- 论文图表/结论表里的数字**只能是最终冻结结果**。
- 探索期"好看的数字"想用，必须先在冻结协议下重跑确认，否则删除。
- 同一指标三态数值差异巨大 → 存在泄漏或不稳定，回溯整改。

随机环节必须固定种子（切分/初始化/集成采样/蒙特卡洛分别记录），并留环境快照（Python 与库版本、数据快照，内容一致性按字节比对）。

---

## 3. 一致性检查

1. **跨种子**：种子敏感模型跑 ≥5 个种子记均值±标准差；离群 >2σ 排查种子或泄漏。
2. **跨环境**：换机/干净环境重跑冻结脚本，核对产物内容（逐字节比对）与关键数值。
3. **数值自洽**：分项之和=合计；RMSE≥MAE；预测 R²>0.999 即过拟合或泄漏嫌疑。
4. **图数一致**：图中读出的数值与结果表一致，禁止"手绘美化"。

轻量留痕：不建额外审计表——关键结果 CSV/JSON + `code/` 脚本 + `results/论文评审与分析.md` 的结果说明即可。

---

## 4. 不确定性、失败与适用范围

- **不确定性**：置信/预测区间（如 95% PI）、多种子均值±标准差、蒙特卡洛分位数（P5/P50/P95）。
- **失败与负面结果**：记录未晋级挑战者及败因、尝试后弃用的方法——证明做了真实比较，是加分项。
- **适用范围**：哪些数据区间有效/失效、假设不成立时结论如何变化。

---

## 5. 假设三链：依据→检验→回退

模型假设不是"列完即止"的装饰段，每条假设必须形成完整闭环：

| 环节 | 要求 | 示例 |
|---|---|---|
| **依据** | 题面/附件/数据/必要简化，短句说明 | "依据：题面第 3 段'忽略次要因素'" |
| **检验** | 给出可操作的验证方法 | "检验：残差自相关检验（Durbin-Watson > 1.8）" |
| **回退**（高风险假设） | 假设不成立时的备选方案 | "不成立则：改用鲁棒回归 / 结论限于 X 范围" |

**低风险假设**（如"忽略空气阻力"）只需依据+检验；**高风险假设**（影响结论成立的关键前提，如"数据独立同分布"）必须三链齐全。

**自检**：
- [ ] 每条假设都有"依据"且来源明确？
- [ ] 每条假设都有"检验"方法且可在代码中实现？
- [ ] 高风险假设都有"不成立则"回退方案？
- [ ] 检验结果已在代码中执行并记录到 `results/`？

---

## 6. 审计自检清单（提交前必过）

- [ ] 论文每个结论性数字都能定位到结果文件、生成代码或图表？
- [ ] 所有随机环节固定种子并记录？环境快照已留档？
- [ ] 论文数字全部来自"冻结"态，无探索态混入？
- [ ] 跨种子一致性已检查（无 >2σ 离群未解释）？
- [ ] 关键结果文件与代码在当前项目中可复跑？
- [ ] 不确定性、失败实验、适用范围均已如实报告？
- [ ] `results/` 实际存在且路径与论文引用一致？

---

## 7. 数据泄漏自查清单

数据泄漏是"数字好得不像真"的头号原因：

- [ ] 测试集是否参与了标准化/归一化统计量计算？（应只用训练集 fit）
- [ ] 特征工程是否用到测试集信息（未来值、标签泄漏）？
- [ ] 交叉验证是否先切分再在训练折内选特征/调参？
- [ ] 时间序列是否按时间顺序切分？
- [ ] SMOTE 是否只作用于训练折？
- [ ] 同一指标三态差异是否异常大？

任何一项命中，立即回退整改，并在 `results/论文评审与分析.md` 记录原因与修复。
