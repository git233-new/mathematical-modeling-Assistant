# 统计分析与数据处理类算法选型卡

> 蒸馏自原 05-统计分析与数据处理算法说明.md（原理推导与代码已删，只留选型决策）。选用前必核：假设、数据规模、目标、约束、验证方式、依赖。

## 选择指南
- 按数据特征：有缺失→KNN/均值填充；有异常→鲁棒检测；高维→PCA/因子分析；非正态→非参数检验、Box-Cox；分类型→卡方检验。
- 按目的：清洗→缺失/异常处理；降维→PCA、因子分析、t-SNE；分组→K-Means/层次/DBSCAN；组间比较→t检验/ANOVA/非参数；相关→相关系数、CCA。
- 按样本量：<30→非参数检验、精确检验；30–500→t检验、方差分析；>500→聚类、PCA、各检验均可。

## 数据预处理
- 适用：缺失值、异常值、标准化、偏态变换
- 前提/假设：Box-Cox要求数据为正，含负值用Yeo-Johnson
- 常见坑：有异常值用中位数填充；异常判定3σ（|Z|>3）或箱线图1.5×IQR、MAD阈值3.5
- 验证：QQ图查正态性；变换前后偏度对比
- 依赖：sklearn.preprocessing/impute、scipy.stats

## K-Means
- 适用：客户细分、文本聚类
- 前提/假设：需指定K；簇近球形，先标准化
- 常见坑：对初值敏感（n_init多次）；K用肘部法则或轮廓系数定
- 验证：轮廓系数、肘部图
- 依赖：sklearn.cluster

## 层次聚类 / DBSCAN / SOM / GMM
- 层次聚类：适用树状结构（基因表达）；链接常用ward；坑：大样本开销大。依赖sklearn
- DBSCAN：适用任意形状簇、异常检测；无需K，需调eps与min_samples（默认5）；坑：密度不均失效。依赖sklearn
- SOM：适用高维拓扑保持降维可视化；需数千次迭代。依赖minisom
- GMM：适用概率软分配、不确定性建模；分量数用BIC/AIC选；协方差full最灵活。依赖sklearn.mixture

## 假设检验（t / ANOVA / 卡方 / 非参数）
- 适用：两组比较→t检验（单样本/独立/配对）；多组→单因素ANOVA；分类变量→卡方；非正态或小样本→Mann-Whitney U（独立）、Wilcoxon符号秩（配对）、Kruskal-Wallis（多组）
- 前提/假设：t/ANOVA要正态且方差齐（不齐用Welch）
- 常见坑：先做Shapiro-Wilk正态性检验（α=0.05）；p<α才拒绝原假设；多重比较需校正
- 验证：报告p值、置信区间、效应量（eta²、Cramer's V）
- 依赖：scipy.stats

## PCA
- 适用：高维降维、消除共线性、2D/3D可视化、去噪
- 前提/假设：线性结构；先Z-score标准化
- 常见坑：主成分无原始变量含义；成分数取累计解释方差≥0.95或碎石图拐点
- 验证：碎石图、累计方差比、载荷图
- 依赖：sklearn.decomposition.PCA

## 因子分析（FA）/ 典型相关（CCA）
- FA：适用潜在变量结构（问卷、风险因子）；因子数用Kaiser准则（特征值>1）+碎石图；旋转常用Varimax。依赖factor_analyzer
- CCA：适用两组变量整体相关（指标与股市、气候与植被）；显著性用Wilks' Lambda卡方近似（α=0.05）。依赖numpy/scipy

## NMF
- 适用：非负数据分解（主题建模、图像特征、推荐）
- 前提/假设：数据全非负；需指定秩r
- 常见坑：对比PCA：NMF基稀疏可解释"部分-整体"，PCA全局正交；r用重构误差曲线选
- 验证：重构误差、主题词可读性
- 依赖：sklearn.decomposition.NMF
