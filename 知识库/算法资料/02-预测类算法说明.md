# 预测类算法选型卡

> 蒸馏自原 02-预测类算法说明.md（原理推导与代码已删，只留选型决策）。选用前必核：假设、数据规模、目标、约束、验证方式、依赖。

## 选择指南

按数据规模选：
| 数据规模 | 推荐算法 |
|---|---|
| 极小样本（<20） | 灰色预测、多项式拟合 |
| 小样本（20-100） | 灰色预测、SVR（避免过拟合） |
| 中等样本（100-10000） | ARIMA、Prophet、回归 |
| 大样本（>10000） | 神经网络、深度学习 |

按数据特征选：
| 数据特征 | 推荐算法 |
|---|---|
| 单调增长/下降 | 灰色预测、趋势回归 |
| 季节性+趋势 | Holt-Winters、Prophet、SARIMA |
| 平稳时间序列 | ARIMA、指数平滑 |
| 非线性关系 | SVR、神经网络 |
| 多变量预测 | 多元回归、VAR、LSTM |
| 小样本+线性 | 线性回归 |
| 小样本+非线性 | SVR、RBF网络 |

按预测目标选：
| 预测目标 | 推荐算法 |
|---|---|
| 短期（<1周） | 指数平滑、ARIMA |
| 中期（1周-3月） | ARIMA、Prophet |
| 长期（>3月） | 灰色预测、神经网络 |
| 点预测 | 回归、SVR |
| 区间预测 | ARIMA、Prophet、贝叶斯方法 |
| 概率预测 | 贝叶斯方法、分位数回归 |

通用指标：R²、调整R²、RMSE、MAE、MAPE。常备图：预测对比、残差、误差分布、置信区间。

## 灰色预测（GM(1,1)）
- 适用：小样本、贫信息、非负、趋势明显的序列；GDP、人口、电力负荷、污染物浓度等短期预测
- 前提/假设：数据非负、近似指数增长；累加生成（AGO）弱化随机性；样本极少（可<20）仍可用
- 常见坑：只适合短期，长期外推失真；波动大/非单调时效果差；发展系数 a 过大时失效
- 验证：残差检验（平均相对误差<5%为佳）、关联度检验（>0.6）、后验差检验（C<0.35 且 P>0.95 优秀；C<0.5 且 P>0.8 良好；C<0.65 且 P>0.7 合格）
- 依赖：numpy

## 插值与拟合
- 适用：数据补全（缺失值填充）、曲线拟合（带噪声数据的趋势分析）、数据平滑、函数逼近、图像缩放
- 前提/假设：插值要求过全部数据点（数据准确无噪声）；拟合允许误差（数据含噪声）；高次多项式插值有 Runge 现象（振荡），节点多时改用分段线性或三次样条
- 常见坑：高次拉格朗日插值在区间端点剧烈振荡；多项式拟合次数过高过拟合，需结合 R²/调整R² 选次数
- 验证：R²、RMSE、残差图
- 依赖：scipy.interpolate（interp1d、CubicSpline）、scipy.optimize.curve_fit、numpy.polyfit、sklearn.metrics

## 线性回归
- 适用：自变量与因变量近似线性关系；经济预测、销量与广告、房价多因素预测、生产函数；小样本+线性首选
- 前提/假设：线性关系、误差独立同分布、残差近似正态、无严重多重共线性
- 常见坑：多重共线性使系数失真——用岭回归（L2）或 Lasso（L1，兼特征筛选）；高维小样本必用正则化；变量筛选用 AIC/BIC/调整R² 或逐步回归
- 验证：R²、调整R²、F检验、系数 p 值（p<0.05 显著）、残差图与 QQ 图（正态性）
- 依赖：sklearn.linear_model（LinearRegression、Ridge、Lasso）、statsmodels（OLS 给完整统计量）

## 神经网络（BP / RBF / LSTM）
- 适用：大样本（>10000）复杂非线性预测；多维时间序列（LSTM）；股票、电力负荷等时序依赖问题
- 前提/假设：数据量充足、可数值化；BP 为多层非线性映射，RBF 适合局部逼近，LSTM 适合长时序依赖
- 常见坑：小样本极易过拟合；需归一化；用 Dropout（如 0.2）、早停抑制过拟合；训练成本高、调参敏感
- 验证：训练/验证损失曲线（learning curve）、留出集或交叉验证、预测对比图
- 依赖：tensorflow/keras（Dense、LSTM、Dropout）或 pytorch

## 支持向量回归（SVR）
- 适用：小样本（20-100）非线性回归预测：股价、房价、负荷/流量预测；高维函数逼近
- 前提/假设：需先标准化/归一化（对尺度敏感）；核函数选择决定非线性能力（RBF 核最常用）
- 常见坑：忘记标准化导致性能崩塌；关键超参数 C（正则强度）、epsilon（不敏感带）、gamma 需网格搜索（如 C∈{0.1,1,10,100}）；大样本训练慢
- 验证：K 折交叉验证 + GridSearchCV（scoring='neg_mean_squared_error'）、RMSE
- 依赖：sklearn.svm.SVR、sklearn.preprocessing.StandardScaler

## ARIMA(p,d,q)
- 适用：单变量平稳化时间序列的中期预测：经济指标、销量、利率、气温；含趋势+季节性时用 SARIMA
- 前提/假设：序列经 d 次差分后平稳——先用 ADF 检验（看 p-value）；AR(p) 自回归 + I(d) 差分 + MA(q) 移动平均
- 常见坑：不检验平稳性直接建模；阶数 (p,d,q) 用 ACF/PACF 图定或按 AIC 网格搜索（max_p=5, max_d=2, max_q=5 遍历取最小 AIC）；只适合单变量
- 验证：ADF 平稳性检验、残差白噪声检验、区间图
- 依赖：statsmodels.tsa（ARIMA、adfuller、plot_acf/plot_pacf）

## 指数平滑（Simple / Holt / Holt-Winters）
- 适用：短期预测：销售、库存需求、指标监测；三种变体按数据特征选——无趋势无季节→简单指数平滑；有趋势无季节→Holt；趋势+季节→Holt-Winters（seasonal_periods 如 12 月度）
- 前提/假设：近期数据权重更大；数据平稳或线性趋势+固定周期季节波动
- 常见坑：数据有明显季节性却只用简单指数平滑；平滑系数 α/β/γ 可优化自动定；只适合短期，长期外推差
- 验证：时序预测对比图、趋势/季节分解图、误差分析
- 依赖：statsmodels.tsa.holtwinters（SimpleExpSmoothing、Holt、ExponentialSmoothing）

## Prophet
- 适用：有强季节性和节假日效应的商务时间序列：销量、网站流量、用户增长、库存需求；中等样本即可
- 前提/假设：y(t)=趋势 g(t)+季节 s(t)+节假日 h(t)+误差；要求 DataFrame 两列 'ds'（日期）和 'y'（值）；趋势可线性或逻辑斯谛
- 常见坑：日期列格式不对直接报错；可加自定义季节性（如月度 period=30.5, fourier_order=5）；节假日效应需手动传入 holidays 表
- 验证：预测分解图（趋势/季节/节假日各组件贡献）、不确定性区间图
- 依赖：prophet、pandas

## XGBoost / LightGBM
- 适用：表格结构化数据预测的通用强基线：销量、用户行为、股价/负荷（构造序列特征后）、分类预测、不平衡数据（欺诈检测）
- 前提/假设：以决策树为基学习器的梯度提升；可处理分类/回归/排序；对缺失值和量纲不敏感
- 常见坑：过拟合——控制 max_depth（如 6）、learning_rate（如 0.1）、subsample/colsample_bytree（如 0.8），务必用早停（early_stopping_rounds≈10）；LightGBM 用直方图加速、Leaf-wise 增长，大数据更快；调参用 GridSearchCV（max_depth{3,5,7} × learning_rate{0.01,0.1,0.2} × n_estimators{100,200,500}）
- 验证：K 折交叉验证、学习/验证曲线、特征重要性图、SHAP 值图
- 依赖：xgboost、lightgbm、sklearn.model_selection

## 时空预测（STARIMA / STGCN 等）
- 适用：时间+空间双依赖数据：交通流量/地铁客流（路网图）、空气质量（空间扩散）、疫情传播（区域扩散）、区域电网负荷、区域经济指标
- 前提/假设：数据表示为 N 个空间节点 × T 时间步 × F 特征；需先构建空间邻接图（距离/相似度权重+连接阈值）
- 常见坑：忽略空间依赖只用普通时序模型会欠拟合；GCN 捕获空间依赖、TCN 捕获时间模式；深度模型需大样本和 GPU
- 验证：RMSE、MAE、MAPE；时空热力图对比真实/预测、误差空间分布图
- 依赖：torch（含 torch.nn）、networkx（建图）、numpy
