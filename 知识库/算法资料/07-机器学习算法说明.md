# 机器学习类算法选型卡

> 蒸馏自原 07-机器学习算法说明.md（原理推导与代码已删，只留选型决策）。选用前必核：假设、数据规模、目标、约束、验证方式、依赖。

## 选择指南

按问题类型选：
| 问题类型 | 推荐算法 |
|---|---|
| 分类问题 | 随机森林、AdaBoost（集成学习） |
| 回归问题 | 随机森林（鲁棒性强） |
| 异常检测 | 孤立森林（无监督） |
| 特征选择 | 随机森林、AdaBoost（特征重要性） |
| 高维数据 | 随机森林（特征随机选择） |
| 不平衡数据 | AdaBoost、随机森林（可调整权重） |

按数据特征选：
| 数据特征 | 推荐算法 |
|---|---|
| 含缺失值 | 随机森林、XGBoost |
| 高维度 | 随机森林、孤立森林 |
| 小样本 | 随机森林（用 OOB 验证） |
| 非线性关系 | 随机森林、AdaBoost |
| 需要概率输出 | 随机森林、AdaBoost |
| 噪声较多 | 随机森林 |

按解释性要求选：
| 解释性要求 | 推荐算法 |
|---|---|
| 需要特征重要性 | 随机森林、AdaBoost |
| 需要决策规则 | 随机森林（单棵树） |
| 需要预测概率 | 随机森林、AdaBoost |
| 黑箱可接受 | 所有集成学习 |

## 随机森林（Random Forest, RF）
- 适用：分类（客户流失、疾病诊断）、回归（房价、销量）、高维数据特征选择、含缺失值/噪声多的数据、不平衡数据（欺诈检测）
- 前提/假设：Bagging 有放回抽样 + 节点分裂时随机选特征，降低方差；对量纲不敏感、无需假设数据分布
- 常见坑：树数 n_estimators（如 100，可画 OOB 误差曲线确认够用）；分类用多数投票、回归取树平均；树太深会过拟合，可限 max_depth
- 验证：OOB 误差（袋外样本，交叉验证的免费替代，oob_score=True）、交叉验证、特征重要性（Gini 重要性 / 置换重要性）、偏依赖图
- 依赖：sklearn.ensemble（RandomForestClassifier/Regressor）、sklearn.inspection（PartialDependenceDisplay）

## AdaBoost（Adaptive Boosting）
- 适用：二分类（欺诈检测、垃圾邮件，标签不平衡场景）、多分类、回归（价格/需求预测，AdaBoost.R2）、模型融合提升性能
- 前提/假设：迭代训练一系列弱分类器，每轮加大之前分错样本的权重，最后加权组合成强分类器；基分类器常用决策树桩（max_depth=1，回归用 max_depth=3）
- 常见坑：对噪声和离群点敏感（错分样本被反复加权）；学习率 learning_rate 与 n_estimators 权衡；回归损失可选 linear/square/exponential
- 验证：训练/测试错误率随轮数变化的曲线（staged_predict）、特征重要性、决策边界图（2D 特征）
- 依赖：sklearn.ensemble（AdaBoostClassifier/Regressor）、sklearn.tree

## 孤立森林（Isolation Forest, iForest）
- 适用：无监督异常检测：信用卡欺诈（极度不平衡）、网络入侵、设备故障（传感器数据）、数据清洗（异常值识别）、罕见模式识别
- 前提/假设：异常点"少数且不同"，随机分割特征空间时被更早隔离（路径更短）；无需假设数据分布，线性时间复杂度，可处理高维数据
- 常见坑：需设定 contamination（预期异常比例，如 0.1）——应做污染率敏感性分析（扫 contamination 比较精确率/召回率/F1）；predict 输出 -1=异常、1=正常，score_samples 需取负才是异常程度；异常得分 s≈1 为异常，s<0.5 为正常
- 验证：有真标签时用 ROC/AUC、分类报告（precision/recall/F1）；无标签时看异常得分分布直方图、异常点散点图
- 依赖：sklearn.ensemble.IsolationForest、sklearn.metrics（roc_auc_score、classification_report）
