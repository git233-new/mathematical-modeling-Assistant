## 一、什么时候用图 / 用表

### 图的类型

- **流程图（按需放）**：总体研究思路 / 技术路线；各小问递进关系；数据→结果流程；算法流程。使用条件与内容要求见 `文档/论文写作.md`。
  节点文字用任务变量、动作和判定写成短语，避免整齐泛化的“分析数据”“建立模型”块；节点正文不小于 14 pt，主节点可用 16 pt。
- **原理图**：机理说明、几何关系、状态转移、变量耦合、模型结构。用来澄清公式/假设/系统关系，
  **不替代推导**。
- **结果图**：趋势、排名、预测 vs 真实、残差、空间分布、基准 vs 主模型对比。
  必须来自模型输出文件，含清晰坐标轴、相关单位、可读标签、明确结论。
- **稳健性图**：灵敏度曲线、排名稳定性、扰动效应、误差分布、种子稳定性、约束灵敏度。
  必须来自**已完成的**检验；未跑的检验不能当证据。

### 表的类型

- **数据概览表**：字段名、单位、缺失值、描述统计、预处理动作（与数据审计报告一致）。
- **符号表**：变量 / 参数 / 集合 / 下标 / 单位 / 定义（决策变量、状态变量、参数、输入、输出分开）。
- **模型结果表**：分数、排名、预测值、最优决策、目标值、参数估计。每个数字都能溯源到结果文件。
- **对比表**：基准 vs 主模型、方法备选、情景对比、前后对比。写清对比标准。
- **灵敏度表**：权重扰动、参数扰动、约束变化、情景结果；含扰动设置与对结论的影响。

保留表的取舍规则见 `文档/论文写作.md`。

## 二、图题

- 图题在**图下居中**：`图 1 各车间工序流程图`；编号全局连续、无缺号。
- 好的图题说明"读者应学到什么"，而非仅命名：

  ```text
  差：图 3 预测结果。
  好：图 3 测试集实际值与预测值对比。主模型贴合短期趋势，但对最后两个高需求点存在低估。
  ```

  图题不要夸大图所展示的内容。

## 四、常见错误（一律避免）

- 图无数据来源、表有编造值；
- 装饰性流程图、重复表达同一信息的图；
- 图强烈暗示超出结果支撑的结论；
- 稳健性图基于"计划但未运行"的检验；
- 结果表与论文正文数字不一致。

> 机器可检项（字体/分辨率/中文标签/英文标签等）由 `文档/图片闸门配置与绘图规范.md` 自动检查，此处不重复。

## 五、实用原则

- 精确值用表，模式 / 趋势 / 对比 / 稳定性用图。
- 导出优先级：SVG（文字可编辑）> PNG 300 DPI（插 docx）> 仅 PNG。
- 图表职责分工见 `文档/样式统一规定.md` §六，此处不重复。
