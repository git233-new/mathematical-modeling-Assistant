# 问题分类

> **用途**：按子问题产出归类（预测/优化/评价/分类/图论/仿真），供算法索引和建模选型使用。
> **依赖**：`知识库/建模增强/模型选型决策矩阵.md`
> **被引**：`文档/论文写作.md`、`知识库/算法索引.md`


## 宽画像路由

> 六类画像（几何/机理、优化/决策、数据/预测、评价/分类、图论/网络、仿真/不确定性）的信号词与产出表**唯一权威见 `文档/论文写作.md §4.0.1`**，此处不再重复；先按子问题产出选画像，再回到下方标准类型做精细归类。

## 为何分类重要

问题类型影响:

- 哪些模型家族是合理的
- 需要什么数据
- 期望的结果格式是什么
- 需要什么验证
- 后续应检查哪些风险

类型判错通常导致模型选错。例如,要求排名的任务,不应仅因为数据集带有时间字段就当作预测任务;要求分配方案的任务,不应止步于描述性分析。

## 分类原则

按**要求的产出**分类,而非按题面标题分类。

用以下问题判断:

1. 这个子问题要求团队产出什么?
2. 产出是分数、预测值、决策、解释、分组、路径、仿真结果,还是数据洞察?
3. 什么样的证据能让答案可接受?
4. 该子问题是否依赖更早子问题的产出?

若一个问题包含多个子问题,逐个分别归类。

## 标准类型

统一使用以下标签(英文标识符保持原样,供程序与 JSON 使用):

```text
evaluation              评价
prediction              预测
optimization            优化
mechanism               机理建模
classification-clustering 分类/聚类
graph-routing           图论/路由
simulation              仿真
data-analysis           数据分析
hybrid                  混合型
```

## 类型指南

> 各类型的候选方法族与最低检查项已统一归入 `知识库/建模增强/模型选型决策矩阵.md`（唯一权威），本文件只保留分类信号、典型产出与常见风险。

### 评价(Evaluation)

当主要产出是分数、排名、等级、优先级顺序、风险等级或综合评价时使用。

常见措辞:

- 评价
- 排序
- 比较
- 评定
- 打分
- 确定重要性
- 建立指标体系
- 综合评价

典型产出:

- 排名表
- 得分表
- 指标权重
- 评价等级
- 优先级列表

常见风险:

- 指标随意设定
- 权重随意设定
- 正、负向指标混淆
- 重复指标对同一因素重复计数
- 排名未做灵敏度检查

### 预测(Prediction)

当主要产出是未来值、未知值估计、趋势、预测区间或不确定性估计时使用。

常见措辞:

- 预测
- 预报
- 估计
- 推断未来
- 趋势
- 外推
- 填补缺失值

典型产出:

- 预测值
- 趋势曲线
- 误差指标
- 预测区间
- 残差分析

常见风险:

- 把训练拟合当作未来表现
- 无验证划分
- 无误差指标
- 特征泄露
- 过度声称长期预测
- 用小数据套用高容量模型

### 优化(Optimization)

当主要产出是带约束的决策方案时使用。

常见措辞:

- 优化
- 最大化
- 最小化
- 分配
- 调度
- 指派
- 选择
- 路由
- 设计方案
- 确定最佳策略

典型产出:

- 决策变量
- 目标函数值
- 可行方案
- 分配表
- 排程
- 路径
- 约束满足报告

常见风险:

- 决策变量不清
- 目标函数无实际意义
- 约束缺失
- 方案数学上最优却不可实施
- 只报最优值而不给实际决策方案

### 机理建模(Mechanism)

当主要产出是系统如何运行或演化的解释时使用。

常见措辞:

- 解释机理
- 描述过程
- 推导关系
- 建模演化
- 由规则仿真动力学
- 分析传播、增长、衰减、流动、运动或相互作用

典型产出:

- 方程
- 状态变量
- 参数估计
- 过程解释
- 动态曲线
- 边界条件

常见风险:

- 变量未定义
- 单位不一致
- 参数无来源
- 假设过强
- 未用数据或常识验证

### 分类/聚类(Classification-clustering)

当主要产出是标签、分组、细分、类别或异常时使用。

常见措辞:

- 分类
- 聚类
- 分组
- 细分
- 识别类别
- 检测异常样本
- 划分类型

典型产出:

- 类别标签
- 聚类归属
- 异常清单
- 混淆矩阵
- 聚类有效性指标
- 特征重要性或解释

常见风险:

- 有监督分类却无标签
- 聚类数随意设定
- 忽略特征缩放
- 类别不平衡
- 无验证指标
- 事后才给缺乏证据的"聚类解释"

### 图论/路由(Graph-routing)

当问题天然涉及节点、边、路径、路线、网络、流或匹配时使用。

常见措辞:

- 网络
- 路径
- 路线
- 最短路
- 流
- 匹配
- 连通性
- 节点重要性
- 运输
- 路由

典型产出:

- 路线方案
- 最短路
- 流量分配
- 匹配结果
- 网络结构
- 节点排序
- 连通性分析

常见风险:

- 图的抽象忽略了真实约束
- 边权随意设定
- 静态网络假设掩盖了时变约束
- 路线数学上成立却实际不可行

### 仿真(Simulation)

当主要产出是场景结果、随机结果分布或重复过程行为时使用。

常见措辞:

- 仿真
- 场景
- 随机
- 概率分布
- 蒙特卡洛
- 重复试验
- 智能体行为
- 随机过程

典型产出:

- 场景表
- 分布摘要
- 置信区间
- 仿真曲线
- 策略对比
- 期望与方差

常见风险:

- 隐藏的随机假设
- 未固定随机种子
- 试验次数过少
- 无统计摘要
- 场景设计缺乏依据

### 数据分析(Data-analysis)

当主要产出是建模前的描述性发现、模式、相关性、因素关系或数据洞察时使用。

常见措辞:

- 数据分析
- 描述模式
- 识别影响因素
- 探索关系
- 概括特征
- 比较分布

典型产出:

- 描述性统计
- 相关表
- 分布图
- 特征关系
- 因素解释
- 数据质量发现

常见风险:

- 把相关当作因果
- 装饰性图表
- 分析与后续建模脱节
- 忽略缺失值或异常值

### 混合型(Hybrid)

当不同子问题需要不同任务类型,或某一阶段产出作为另一阶段输入时使用。

常见模式:

- 评价 → 预测 → 优化
- 数据分析 → 预测 → 决策
- 机理模型 → 参数拟合 → 仿真
- 分类 → 评价 → 推荐
- 预测 → 路由或分配

典型产出:

- 分阶段工作流
- 依赖关系图
- 中间产物
- 最终集成建议

常见风险:

- 把整道题当作单一类型
- 用同一个模型回答互不相关的子问题
- 跳过子问题间的依赖
- 各阶段变量不一致
- 论文章节与实际工作流不符

## 常见误分类模式

### 预测 vs 评价

若产出是排名或分数,通常是评价。

若产出是未来值或未知值估计,则是预测。

带有时间字段的数据集,不会自动让问题变成预测问题。

### 数据分析 vs 建模

若任务只要求模式、关系或描述性发现,可能是数据分析。

若任务需要决策、预测、排名或机理,数据分析只是支撑性阶段。

### 优化 vs 评价

若任务问"哪个更好",通常是评价。

若任务问"在约束下我们该选什么",通常是优化。

### 仿真 vs 预测

若任务要求从历史数据得到未来值,通常是预测。

若任务要求场景或随机过程下的行为,通常是仿真。

### 机理 vs 回归

若任务需要可解释的进程或定律式关系,可能需要机理建模。

若任务只需从输入到输出的经验映射,回归或预测通常已足够。

## 分类产物的输出格式

一份有用的分类产物应包含:

```json
{
  "subquestion_classifications": [
    {
      "id": "Q1",
      "primary_type": "evaluation",
      "secondary_type": "data-analysis",
      "reason": "要求的产出是基于多个指标得到的排名。",
      "expected_outputs": [
        "得分表",
        "排名表"
      ],
      "candidate_method_families": [
        "指标体系构建",
        "多准则评价"
      ],
      "risks": [
        "指标权重需提供依据",
        "应检查排名稳定性"
      ]
    }
  ],
  "global_pattern": "hybrid",
  "dependency_notes": [
    "Q2 以 Q1 的得分作为输入。"
  ]
}
```

## 实用原则

拿不准时,先写下要求的产出。

产出通常会告诉你它属于哪一类。
