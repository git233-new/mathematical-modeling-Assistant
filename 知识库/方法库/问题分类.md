# 问题分类

> 本文件定义问题类型，供 `知识库/算法索引.md` 等按子问题归类使用（宽画像快速路由见本文末「宽画像路由」小节；解题分析规范见 `文档/论文写作.md §8`）。目的不是用一词给整道竞赛题贴标签——多数建模竞赛题都是混合型的。有用的单位是**子问题**:按"它要求什么、需要什么产出"对每个子问题分别归类。
>
> 配套：`知识库/建模增强/模型选型决策矩阵.md`（按问题类型→候选方法族的决策矩阵）。本文件负责问题分类，方法选型以决策矩阵为准。


## 宽画像路由（快速定位，配套使用）

> 本小节为详细分类前的宽口径快速路由：先按子问题产出粗分画像，再回到上方标准类型做精细归类。画像可多选，不替代正式分类标签。

本文件只负责把新题送到合适的参考范围，不负责替题目决定最终模型。画像按数学产出和对象划分，保持宽口径；一道题可以同时命中多个画像。

## 六类画像

| 画像 | 题面信号 | 常见产出 | 优先查看 |
|---|---|---|---|
| 几何/机理 | 反射、投影、受力、运动、传热、扩散、守恒、演化 | 几何关系、方程、轨迹、场分布、参数 | 几何约束、守恒关系、微分方程、数值求解 |
| 优化/决策 | 分配、调度、选址、指派、资源、容量、策略、最优 | 可行方案、目标值、排程、决策表 | 目标函数、约束、可行性、简单基线 |
| 数据/预测 | 预测、估计、趋势、回归、时序、拟合、误差 | 预测值、区间、趋势、误差分析 | 数据清洗、特征、训练/检验划分、误差指标 |
| 评价/分类 | 评价、排序、权重、指标、分级、识别、聚类、异常 | 得分、排名、类别、异常清单 | 指标方向、权重、分类/聚类有效性、稳定性 |
| 图论/网络 | 节点、边、路径、路线、连通、覆盖、流量、匹配 | 路径、网络结构、流量、匹配方案 | 图抽象、边权、路径约束、网络可行性 |
| 仿真/不确定性 | 场景、随机、概率、风险、扰动、鲁棒、蒙特卡洛 | 场景分布、置信区间、风险、策略比较 | 随机设定、试验次数、统计摘要、情景边界 |

## 使用顺序

1. 先按每个子问题的最终产出选画像，不按题号、年份或赛题字母选画像。
2. 再用变量、约束、数据字段和方法词筛方法卡；画像相同不代表模型可以照搬。
3. 参考案例只迁移问题抽象、公式组织、图表职责和检查思路；变量、参数、公式、代码和数字必须重新建立。
4. 若题目是混合型，保留多个画像并画一张问题分析流程图，标明各问之间传递的输入和输出。

## 写入大纲

```json
{
  "problem_profiles": ["几何/机理", "优化/决策"],
  "subquestions": [
    {"id": "Q1", "profile": "几何/机理", "output": "反射点坐标与误差"},
    {"id": "Q2", "profile": "优化/决策", "output": "满足约束的方案"}
  ]
}
```

画像是检索和写作组织工具，不是必须写进论文的分类标签。


## 为何分类重要

问题类型影响:

- 哪些模型家族是合理的
- 需要什么数据
- 期望的结果格式是什么
- 需要什么验证
- 后续应检查哪些风险

类型判错通常导致模型选错。例如,要求排名的任务,不应仅因为数据集带有时间字段就当作预测任务;要求分配方案的任务,不应止步于描述性分析。

## 分类原则

按**要求的产出**分类,而非按题面标题分类。

用以下问题判断:

1. 这个子问题要求团队产出什么?
2. 产出是分数、预测值、决策、解释、分组、路径、仿真结果,还是数据洞察?
3. 什么样的证据能让答案可接受?
4. 该子问题是否依赖更早子问题的产出?

若一个问题包含多个子问题,逐个分别归类。

## 标准类型

统一使用以下标签(英文标识符保持原样,供程序与 JSON 使用):

```text
evaluation              评价
prediction              预测
optimization            优化
mechanism               机理建模
classification-clustering 分类/聚类
graph-routing           图论/路由
simulation              仿真
data-analysis           数据分析
hybrid                  混合型
```

## 类型指南

### 评价(Evaluation)

当主要产出是分数、排名、等级、优先级顺序、风险等级或综合评价时使用。

常见措辞:

- 评价
- 排序
- 比较
- 评定
- 打分
- 确定重要性
- 建立指标体系
- 综合评价

典型产出:

- 排名表
- 得分表
- 指标权重
- 评价等级
- 优先级列表

常用方法家族:

- 指标体系构建
- 归一化
- 熵权法
- 层次分析法(AHP)
- TOPSIS
- 灰色关联分析
- 模糊综合评价
- 基于 PCA 的评价

常见风险:

- 指标随意设定
- 权重随意设定
- 正、负向指标混淆
- 重复指标对同一因素重复计数
- 排名未做灵敏度检查

最低检查项:

- 指标方向检查
- 权重合理性说明
- 排名稳定性
- 与等权打分等简单基线的对比

### 预测(Prediction)

当主要产出是未来值、未知值估计、趋势、预测区间或不确定性估计时使用。

常见措辞:

- 预测
- 预报
- 估计
- 推断未来
- 趋势
- 外推
- 填补缺失值

典型产出:

- 预测值
- 趋势曲线
- 误差指标
- 预测区间
- 残差分析

常用方法家族:

- 朴素基线
- 移动平均
- 线性或非线性回归
- 时序模型
- 灰色预测
- 机器学习回归
- 集成预测

常见风险:

- 把训练拟合当作未来表现
- 无验证划分
- 无误差指标
- 特征泄露
- 过度声称长期预测
- 用小数据套用高容量模型

最低检查项:

- 基线对比
- 训练-测试划分或交叉验证(尽量采用)
- MAE、RMSE、MAPE 或任务适配的指标
- 残差或失败案例分析

### 优化(Optimization)

当主要产出是带约束的决策方案时使用。

常见措辞:

- 优化
- 最大化
- 最小化
- 分配
- 调度
- 指派
- 选择
- 路由
- 设计方案
- 确定最佳策略

典型产出:

- 决策变量
- 目标函数值
- 可行方案
- 分配表
- 排程
- 路径
- 约束满足报告

常用方法家族:

- 线性规划
- 整数规划
- 非线性规划
- 动态规划
- 多目标优化
- 网络优化
- 贪心基线
- 启发式搜索
- 遗传算法或模拟退火(用于困难的组合情形)

常见风险:

- 决策变量不清
- 目标函数无实际意义
- 约束缺失
- 方案数学上最优却不可实施
- 只报最优值而不给实际决策方案

最低检查项:

- 决策变量定义
- 目标与约束
- 可行性检查
- 基线对比
- 对关键约束或权重的灵敏度

### 机理建模(Mechanism)

当主要产出是系统如何运行或演化的解释时使用。

常见措辞:

- 解释机理
- 描述过程
- 推导关系
- 建模演化
- 由规则仿真动力学
- 分析传播、增长、衰减、流动、运动或相互作用

典型产出:

- 方程
- 状态变量
- 参数估计
- 过程解释
- 动态曲线
- 边界条件

常用方法家族:

- 微分方程
- 差分方程
- 仓室模型
- 守恒律
- 物理或几何约束
- 系统动力学
- 机理建模 + 参数拟合

常见风险:

- 变量未定义
- 单位不一致
- 参数无来源
- 假设过强
- 未用数据或常识验证

最低检查项:

- 变量与单位一致性
- 参数来源
- 边界条件检查
- 对重要参数的灵敏度

### 分类/聚类(Classification-clustering)

当主要产出是标签、分组、细分、类别或异常时使用。

常见措辞:

- 分类
- 聚类
- 分组
- 细分
- 识别类别
- 检测异常样本
- 划分类型

典型产出:

- 类别标签
- 聚类归属
- 异常清单
- 混淆矩阵
- 聚类有效性指标
- 特征重要性或解释

常用方法家族:

- 基于规则的基线
- 逻辑回归
- 决策树
- 随机森林
- 支持向量机(SVM)
- K-means
- 层次聚类
- DBSCAN
- 异常检测

常见风险:

- 有监督分类却无标签
- 聚类数随意设定
- 忽略特征缩放
- 类别不平衡
- 无验证指标
- 事后才给缺乏证据的"聚类解释"

最低检查项:

- 标签可用性
- 特征缩放
- 类别平衡或聚类有效性
- 准确率、F1、混淆矩阵、轮廓系数或任务适配的指标

### 图论/路由(Graph-routing)

当问题天然涉及节点、边、路径、路线、网络、流或匹配时使用。

常见措辞:

- 网络
- 路径
- 路线
- 最短路
- 流
- 匹配
- 连通性
- 节点重要性
- 运输
- 路由

典型产出:

- 路线方案
- 最短路
- 流量分配
- 匹配结果
- 网络结构
- 节点排序
- 连通性分析

常用方法家族:

- 最短路
- 最小生成树
- 最大流 / 最小费用流
- 匹配
- 车辆路径问题(VRP)
- 图中心性
- 图搜索
- 网络优化

常见风险:

- 图的抽象忽略了真实约束
- 边权随意设定
- 静态网络假设掩盖了时变约束
- 路线数学上成立却实际不可行

最低检查项:

- 节点与边定义
- 边权合理性说明
- 可行性检查
- 与简单路线或贪心基线的对比

### 仿真(Simulation)

当主要产出是场景结果、随机结果分布或重复过程行为时使用。

常见措辞:

- 仿真
- 场景
- 随机
- 概率分布
- 蒙特卡洛
- 重复试验
- 智能体行为
- 随机过程

典型产出:

- 场景表
- 分布摘要
- 置信区间
- 仿真曲线
- 策略对比
- 期望与方差

常用方法家族:

- 蒙特卡洛仿真
- 离散事件仿真
- 基于智能体的仿真
- 随机过程建模
- 场景分析

常见风险:

- 隐藏的随机假设
- 未固定随机种子
- 试验次数过少
- 无统计摘要
- 场景设计缺乏依据

最低检查项:

- 随机种子
- 试验次数
- 参数分布来源
- 置信区间或摘要统计量
- 对场景假设的灵敏度

### 数据分析(Data-analysis)

当主要产出是建模前的描述性发现、模式、相关性、因素关系或数据洞察时使用。

常见措辞:

- 数据分析
- 描述模式
- 识别影响因素
- 探索关系
- 概括特征
- 比较分布

典型产出:

- 描述性统计
- 相关表
- 分布图
- 特征关系
- 因素解释
- 数据质量发现

常用方法家族:

- 描述性统计
- 相关分析
- 假设检验
- 探索性可视化
- PCA 或因子分析
- 回归解释

常见风险:

- 把相关当作因果
- 装饰性图表
- 分析与后续建模脱节
- 忽略缺失值或异常值

最低检查项:

- 数据质量摘要
- 单位与字段含义检查
- 与后续子问题的关联
- 明确区分相关与因果

### 混合型(Hybrid)

当不同子问题需要不同任务类型,或某一阶段产出作为另一阶段输入时使用。

常见模式:

- 评价 → 预测 → 优化
- 数据分析 → 预测 → 决策
- 机理模型 → 参数拟合 → 仿真
- 分类 → 评价 → 推荐
- 预测 → 路由或分配

典型产出:

- 分阶段工作流
- 依赖关系图
- 中间产物
- 最终集成建议

常见风险:

- 把整道题当作单一类型
- 用同一个模型回答互不相关的子问题
- 跳过子问题间的依赖
- 各阶段变量不一致
- 论文章节与实际工作流不符

最低检查项:

- 逐子问题分别归类
- 识别依赖关系
- 定义阶段间传递的产物
- 检查各阶段变量与输出的一致性

## 常见误分类模式

### 预测 vs 评价

若产出是排名或分数,通常是评价。

若产出是未来值或未知值估计,则是预测。

带有时间字段的数据集,不会自动让问题变成预测问题。

### 数据分析 vs 建模

若任务只要求模式、关系或描述性发现,可能是数据分析。

若任务需要决策、预测、排名或机理,数据分析只是支撑性阶段。

### 优化 vs 评价

若任务问"哪个更好",通常是评价。

若任务问"在约束下我们该选什么",通常是优化。

### 仿真 vs 预测

若任务要求从历史数据得到未来值,通常是预测。

若任务要求场景或随机过程下的行为,通常是仿真。

### 机理 vs 回归

若任务需要可解释的进程或定律式关系,可能需要机理建模。

若任务只需从输入到输出的经验映射,回归或预测通常已足够。

## 分类产物的输出格式

一份有用的分类产物应包含:

```json
{
  "subquestion_classifications": [
    {
      "id": "Q1",
      "primary_type": "evaluation",
      "secondary_type": "data-analysis",
      "reason": "要求的产出是基于多个指标得到的排名。",
      "expected_outputs": [
        "得分表",
        "排名表"
      ],
      "candidate_method_families": [
        "指标体系构建",
        "多准则评价"
      ],
      "risks": [
        "指标权重需提供依据",
        "应检查排名稳定性"
      ]
    }
  ],
  "global_pattern": "hybrid",
  "dependency_notes": [
    "Q2 以 Q1 的得分作为输入。"
  ]
}
```

## 实用原则

拿不准时,先写下要求的产出。

产出通常会告诉你它属于哪一类。
