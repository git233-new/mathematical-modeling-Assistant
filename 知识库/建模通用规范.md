# 建模通用防错规范

> 定位：解题分析期（Step 2-5）防错速查。分工：总则权威 = `SKILL.md` 铁律；选哪个模型 = `建模增强/模型选型决策矩阵.md` + `算法资料/` 选型卡；怎么比较 = `建模增强/冠军挑战者建模流程.md`；写作 = `文档/论文写作.md`；图表 = `方法库/图表规范.md` + `tools/figure/references/画图避坑清单.md`。本文件只保留防错速查，不重复上述内容。

## 赛题理解与子问题识别

- 子问题只认题面明确编号的顶层问题（"问题一/问题二"）；背景描述、数据说明、提交要求不算子问题。
- 每个子问题说清：输入、输出、决策变量/预测对象、评价指标、约束、与其他子问题的依赖。
- 题面模糊表述先列两种以上解释，再用逻辑/验算/递进性判断取舍；不要拿到题就定模型。
- 后续问题增加资源或约束但结果几乎不变 → 回头审查基础假设。

## 选模效率原则

优先选择能快速产出可信首版结果的方案：问题结构清楚、首版快、计算边界可估、可逐步加精、验证成本低、失败可回退（复杂版跑不动仍有简化版交付）。

尽量不用：首轮代码量过大且跑不出结果、结果依赖长时间搜索调参、参数多而无含义、验证本身比求解还麻烦、只高级但不更快更稳更清楚地回答问题。

任何模型进主方案前回答三问：首版多久能跑出来？错了能否快速发现？跑不动有没有简化版？

## 模型严谨性

- 假设必要、可解释、可参数化；物理/业务约束优先级高于拟合好看。
- 有可比基线或验证之前，不得声称更优/全局最优/明显创新。
- 多目标先无量纲化再加权或 Pareto，报告各目标分量贡献；不同量纲指标不得直接相加。
- 启发式不直接宣称全局最优，除非有证明、精确对照或稳定性验证。

## 题型防错速查

- 优化、调度、选址、路径、装箱：不漏非负/整数/容量/预算/时间窗/前驱约束；连续松弛后必须说明取整与修复策略；非凸或启发式做多起点/多种子稳定性检查。
- 多资源多阶段优化：资源变多目标值通常应改善；未改善优先查新增资源是否被目标利用、约束是否写反、是否陷局部最优。
- 多目标：先各目标独立无量纲化再加权或 Pareto；报告分量贡献防大数值目标淹没其他。
- 高维黑箱优化：先变量分组/几何降维/分层优化；不要把十几个以上变量直接丢给 GA/PSO/DE 后接受结果。
- 微分方程、动力学、仿真：写清状态变量单位、初始/边界条件、接触/饱和/反弹约束；刚性系统选合适求解器；检查守恒量、漂移、步长收敛。
- 统计、回归、预测：时序按时间划分；标准化只在训练集 fit；查残差、共线性、异常值、外推范围与预测值物理边界。
- 评价、排名、决策：正负向指标先统一方向，权重和为 1；AHP 查一致性；TOPSIS/熵权/DEA 说明无量纲化方法与排名敏感性。
- 图论、网络流：明确有向/无向、权重、容量、连通性；负权边不能用 Dijkstra；最大流满足流量守恒；TSP/VRP 防子回路与不可行路径。
- 几何、空间布局：有尺寸实体不能降维成中心点；碰撞/遮蔽/覆盖作用于完整边界或给出等价性证明；旋转矩形用 OBB/SAT 不用 AABB；坐标系与角度单位统一。
- 动态规划、博弈、排队：状态空间/转移方程/边界条件完整；排队先验证稳态条件；博弈区分纳什均衡、帕累托最优、最优响应。
- 机器学习：不在测试集调参；类别不平衡要处理；特征工程有业务含义；超参搜索范围与评估指标匹配任务。

## 编码阶段常见错误

- `scipy.optimize.minimize` 只做最小化；最大化目标要取负，并在结果记录还原真实目标值。
- scipy 不等式约束方向是 `fun(x) >= 0`；容量/下界/预算约束最易写反，写完代入边界点检查符号。
- 不只信求解器 `success`：最优解重新代入所有约束，输出每条的值、松弛量、是否活跃。
- 整数/0-1 变量取整后重新验证可行性；不可行用明确修复启发式，不直接四舍五入。
- 物理参数、单位、符号与建模报告一致；不出现不一致的长度/质量/速度/时间步长/坐标原点。
- 数据读取先查编码、列名、形状、单位、缺失值；不在数据错位时继续建模。
- 防泄露：划分后再 fit scaler/encoder；时序不随机打乱；测试集不参与调参。
- 图论代码查节点数、边数、有向性、负权边、连通性、容量；最大流要有残量网络。
- 几何代码不用中心距替代实体碰撞；遮蔽/覆盖函数参数含完整几何尺寸；离散采样做收敛检查。
- 数值代码查条件数、收敛状态、迭代次数、步长减半结果、种子复现、边界输入。
- 结果 JSON/表格保存每个子问题的关键数值、约束检查、图表数据来源与可复现参数；不只把结论写进 Markdown。

## 非数据图工具选择

- DrawIO：技术路线图、求解流程图、数据处理 Pipeline、指标体系层次图、决策树。
- TikZ：需精确数学标注、公式节点、复杂连线、变量关系、因果路径的图。
- Matplotlib/networkx：节点多、数据驱动布局、需标注最优路径/权重的网络图。
- 生成式图片仅限物理/工程场景示意（3D 几何、无人机/传感器场景），不替代需精确公式与可编辑结构的图。
- 图内文字与论文语言一致；图形有明确论文用途并在正文配套解释。
